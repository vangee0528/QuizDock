# 数据结构与算法-q-000341

## 题目

一个算法是对某类给定问题求解过程的精确描述，算法中描述的操作都可以通过将已经实现的基本操作执行有限次来实现，这句话说明算法具有（） 特性。

## 选项

- **A.** 有穷性

- **B.** 可行性

- **C.** 确定性

- **D.** 健壮性

## 参考答案

- **B.** 可行性
