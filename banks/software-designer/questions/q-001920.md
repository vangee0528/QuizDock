# 真题-q-001920

## 题目

在面向对象方法中，将逻辑上相关的数据以及行为绑定在一起，使信息对使用者隐蔽称为（1）。当类中的属性或方法被设计为 private 时，（请作答此空）可以对其进行访问。

## 选项

- **A.** 应用程序中所有方法

- **B.** 只有此类中定义的方法

- **C.** 只有此类中定义的 public 方法

- **D.** 同一个包中的类中定义的方法

## 参考答案

- **B.** 只有此类中定义的方法
