# 真题-q-001720

## 题目

## 选项

- **A.** 工厂方法(Factory Method)

- **B.** 构建器(Builder)

- **C.** 原型(Prototype)

- **D.** 单例(Singleton )

## 参考答案

- **A.** 工厂方法(Factory Method)
