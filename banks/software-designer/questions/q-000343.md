# 数据结构与算法-q-000343

## 题目

现需要对一个基本有序的数组进行排序。此时最适宜采用的算法为（ ）排算法，时间复杂度为（作答此空 ）。

## 选项

- **A.** O(n)

- **B.** O(nlgn)

- **C.** O(n^2)

- **D.** O(n^2lgn)

## 参考答案

- **A.** O(n)
