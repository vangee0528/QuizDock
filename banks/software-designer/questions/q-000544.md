# 数据库-q-000544

## 题目

设关系模式R(U,F), U={A1，A2，A3，A4}，函数依赖集F={A1→A2，A1→A3 ，A2→A4}，关系R的候选码是(52)。下列结论错误的是（请作答此空）。

## 选项

- **A.** A1→A2A3为F所蕴涵

- **B.** A1→ A4为F所蕴涵

- **C.** A1A2→ A4为F所蕴涵

- **D.** A2→ A3为F所蕴涵

## 参考答案

- **D.** A2→ A3为F所蕴涵
