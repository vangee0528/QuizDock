# 数据库-q-000581

## 题目

计算机系统的软硬件故障可能会造成数据库中的数据被破坏。为了防止这一问题，通常需要（  ），以便发生故障时恢复数据库。

## 选项

- **A.** 定期安装DBMS和应用程序

- **B.** 定期安装应用程序，并将数据库做镜像

- **C.** 定期安装DBMS，并将数据库作备份

- **D.** 定期将数据库作备份；在进行事务处理时，需要将数据更新写入日志文件

## 参考答案

- **D.** 定期将数据库作备份；在进行事务处理时，需要将数据更新写入日志文件
