# 真题-q-001384

## 题目

Windows 文件系统的目录结构（C 盘下）如下图所示，假设用户要访问文件 `f2.java`，则该文件的全文件名为（24）。若系统当前工作目录为 `ProgramFile`，那么该文件的相对路径为（请作答此空）。

![题目图片](../assets/388dcd737e2f2a106b18c5c163a397b2bf6558439018947b4b046247e34e715c.jpg)

## 选项

- **A.** `\java-prog\f2.java`

- **B.** `java-prog\f2.java`

- **C.** `Program\java-prog\f2.java`

- **D.** `\Program\java-prog\f2.java`

## 参考答案

- **B.** `java-prog\f2.java`
