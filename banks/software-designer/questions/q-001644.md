# 真题-q-001644

## 题目

（1）设计模式将对象组合成树形结构以表示“部分一整体”的层次结构，使得用户对单个对象和组合对象的使用具有一致性；（2）设计模式定义对象间的一种一对多的依赖关系，当一个对象的状态发生改变时，所有依赖于它的对象都得到通知并被自动更新；欲使一个后端数据模型能够被多个前端用户界面连接，采用（请作答此空）模式最适合。

## 选项

- **A.** 装饰器(Decorator)

- **B.** 享元(Flyweight)

- **C.** 观察者(Observer)

- **D.** 中介者(Mediator)

## 参考答案

- **D.** 中介者(Mediator)
