# 软件工程-q-000943

## 题目

在采用标准UML构建的用例模型（Use-Case Model）中，参与者（Actor）与用例（Use Case）是模型中的主要元素，其中参与者与用例之间可以具有（）关系。

## 选项

- **A.** 包含（include）

- **B.** 递归（Recursive）

- **C.** 关联（Association）

- **D.** 组合（Composite）

## 参考答案

- **C.** 关联（Association）
