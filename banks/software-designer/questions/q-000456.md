# 操作系统-q-000456

## 题目

在UNIX操作系统中，当用户执行如下命令
	link("/user/include/myfile.sh"，"/usr/userwang/youfile.sh")
	则文件名"/usr/userwang/youfile.sh"存放在（ ）。

## 选项

- **A.** user目录文件中

- **B.** include目录文件中

- **C.** userwang目录文件中

- **D.** youfile.sh的文件内容中

## 参考答案

- **C.** userwang目录文件中
