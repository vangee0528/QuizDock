# 真题-q-001405

## 题目

（请作答此空）  设计模式能使一个对象的状态发生改变时通知所有依赖它的监听者。  (  47 )  设计模式限制类的实例对象只能有一个。

## 选项

- **A.** 责任链(chain of responsibility)

- **B.** 命令(command)

- **C.** 抽象工厂(abstract factory)

- **D.** 观察者(observer)

## 参考答案

- **D.** 观察者(observer)
