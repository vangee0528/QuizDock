# 真题-q-002433

## 题目

设有向图G 具有n个顶点、e条弧，采用邻接表存储，则完成广度优先遍历的时间复杂度为  (  )  。

## 选项

- **A.** O(n+e)

- **B.** O(n^2)

- **C.** O(e^2)

- **D.** O(n*e)

## 参考答案

- **A.** O(n+e)
