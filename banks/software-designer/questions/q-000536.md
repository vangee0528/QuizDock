# 数据库-q-000536

## 题目

给定关系 R（A，B，C，D）和关系 S（A，C，E，F），对其进行自然连接运算 R ⋈S 后的属性列为（ ）个；与σR.B>S.E（R⋈S）等价的关系代数表达式为（作答此空）。

## 选项

- **A.** α2>7（R x S）

- **B.** π1,2,3,4,7,8（σ1=5 ˄ 2>7˄3=6（R×S））

- **C.** σ2>'7'（R×S）

- **D.** π1,2,3,4,7,8（σ1=5 ˄ 2>’ 7’ ˄3=6（R×S））

## 参考答案

- **B.** π1,2,3,4,7,8（σ1=5 ˄ 2>7˄3=6（R×S））
