# 程序设计语言-q-000175

## 题目

下面的 C 程序代码段在运行中会出现（ ）错误。

```c
int i = 0;
while (i < 10) ;
{
    i = i + 1;
}
```

## 选项

- **A.** 语法

- **B.** 类型不匹配

- **C.** 变量定义

- **D.** 动态语义

## 参考答案

- **D.** 动态语义
