# 软件工程-q-000716

## 题目

关于软件测试，下列说法中错误的是（36）。

## 选项

- **A.** 在早期的软件开发中，测试就等同于调试

- **B.** 软件测试是使用人工或自动手段来运行或测定某个系统的过程

- **C.** 软件测试的目的在于检验它是否满足规定的需求或是弄清楚预期结果与实际结果之间的差异

- **D.** 软件测试与软件开发是两个独立、分离的过程

## 参考答案

- **D.** 软件测试与软件开发是两个独立、分离的过程
