# 法律法规与知识产权-q-001089

## 题目

甲将其一篇短文《心灵的呼唤》投递给杂志社。未经甲的许可，杂志社便委托乙对甲的短文进行修改，然后杂志社将署名为乙和甲的短文发表在其刊物上，则（ ）。

## 选项

- **A.** 杂志社侵犯了甲的著作权，乙未侵权

- **B.** 杂志社未侵犯甲的著作权，乙侵了权

- **C.** 杂志社和乙均侵犯了甲的著作权

- **D.** 杂志社和乙均未侵犯甲的著作权

## 参考答案

- **C.** 杂志社和乙均侵犯了甲的著作权
