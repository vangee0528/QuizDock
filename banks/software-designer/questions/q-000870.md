# 软件工程-q-000870

## 题目

以下关于封装在软件复用中所充当的角色的叙述，正确的是（  ）。

## 选项

- **A.** 封装使得其他开发人员不需要知道一个软件组件内部如何工作

- **B.** 封装使得软件组件更有效地工作

- **C.** 封装使得软件开发人员不需要编制开发文档

- **D.** 封装使得软件组件开发更加容易

## 参考答案

- **A.** 封装使得其他开发人员不需要知道一个软件组件内部如何工作
