# 真题-q-002029

## 题目

在面向对象技术中，不同的对象在收到同一消息时可以产生完全不同的结果，这一现象称为 （ ） ，它由 （请作答此空） 机制来支持。利用类的层次关系，把具有通用功能的消息存放在高层次，而不同的实现这一功能的行为放在较低层次，在这些低层次上生成的对象能够给通用消息以不同的响应。

## 选项

- **A.** 绑定

- **B.** 继承

- **C.** 消息

- **D.** 多态

## 参考答案

- **B.** 继承
