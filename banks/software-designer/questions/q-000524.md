# 数据库-q-000524

## 题目

若要将部门表 Demp 中 name 列的修改权限赋予用户 Ming，并允许 Ming 将该权限授予他人，实现的 SQL 语句如下：

```sql
GRANT （请作答此空） ON TABLE Demp TO Ming （2）。
```

## 选项

- **A.** SELECT（name）

- **B.** UPDATE（name）

- **C.** INSERT（name）

- **D.** ALL PRIVILEGES（name）

## 参考答案

- **B.** UPDATE（name）
