# 真题-q-001174

## 题目

异常是指令执行过程中在处理器内部发生的特殊事件，中断是来自处理器外部的请求事件。以下关于中断和异常的叙述中，正确的是（）。

## 选项

- **A.** “DMA传送结束”、“除运算除数为0”都为中断

- **B.** “DMA传送结束”为中断、“除运算除数为0”为异常

- **C.** “DMA传送结束”为异常、“除运算除数为0”为中断

- **D.** “DMA传送结束”、“除运算除数为0”都为异常

## 参考答案

- **B.** “DMA传送结束”为中断、“除运算除数为0”为异常
