# 计算机基础-q-000034

## 题目

CD上声音的采样频率为44.lkHz，样本精度为16b/s，双声道立体声，那么其未经压缩的数据传输率为（）。

## 选项

- **A.** 88.2kb/s

- **B.** 705.6kb/s

- **C.** 1411.2kb/s

- **D.** 1536.0kb/s

## 参考答案

- **C.** 1411.2kb/s
