# 真题-q-001452

## 题目

● 某文件管理系统采用位示图.(bitmap)来记录磁盘的使用情况，若计算机系统的字长为64位，磁盘容量为512GB，物理块的大小为4MB，那么位示图的大小为  (  23 )  个字。

## 选项

- **A.** 1024

- **B.** 2048

- **C.** 4096

- **D.** 9600

## 参考答案

- **B.** 2048
