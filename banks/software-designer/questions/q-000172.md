# 程序设计语言-q-000172

## 题目

以下关于语言L={anbn|n>=1}的叙述中，正确的是（  ）。

## 选项

- **A.** 可用正规式“aa*bb*”描述，但不能通过有限自动机识别

- **B.** 可用正规式“ambm”表示，但可用有限自动机识别

- **C.** 不能用正规式表示，但可用有限自动机识别

- **D.** 既不能用正规式表示，也不能通过有限自动机识别

## 参考答案

- **D.** 既不能用正规式表示，也不能通过有限自动机识别
