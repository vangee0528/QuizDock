# 数据库-q-000480

## 题目

序言性注释是指在每个程序或模块开头的一段说明，起辅助理解程序的作用，一般包括：程序的表示、名称和版本号，程序功能描述，接口与界面描述，输入/输出数据说明，开发历史，与运行环境有关的信息等。下列叙述中不属于序言性注释的是（）。

## 选项

- **A.** 程序对硬件、软件资源的要求

- **B.** 重要变量和参数说明

- **C.** 嵌入在程序中的SQL语句

- **D.** 程序开发的原作者、审查者、修改者、编程日期等

## 参考答案

- **C.** 嵌入在程序中的SQL语句
