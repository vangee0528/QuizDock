# 软件工程-q-000777

## 题目

如下所示代码（用缩进表示程序块），要实现语句覆盖，至少需要(问题1)个测试用例。采用McCabe度量法计算该代码对应的程序流程图的环路复杂性为(问题2)。
input A,n
for i=2 to n
    key=A[i]
    j=i-1
    while j>0 and A[j]>key
        A[j+1]=A[j]
        j=j-1
    A[j+1]=key
