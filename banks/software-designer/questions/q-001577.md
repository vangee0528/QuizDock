# 真题-q-001577

## 题目

若浮点数用补码表示,则判断运算结果为规格化数的方法是( )

## 选项

- **A.** 阶符与数符相同为规格化数

- **B.** 阶符与数符相异为规格化数

- **C.** 数符与尾数小数点后第一位数字相异为规格化数

- **D.** 数符与尾数小数点后第一位数字相同为规格化数

## 参考答案

- **C.** 数符与尾数小数点后第一位数字相异为规格化数
