# 真题-q-001513

## 题目

【学员回忆版】以下关于折半查找的叙述中，不正确的是（请作答此空）。采用折半查找等概率查找某个包含 8 个元素的有序表，查找成功的平均查找长度为（）。

## 选项

- **A.** 是一个分治算法

- **B.** 只能应用于有序表

- **C.** 查找成功和不成功的平均查找长度是一样的

- **D.** 若表长为 n，时间复杂度为 O(log n)

## 参考答案

- **C.** 查找成功和不成功的平均查找长度是一样的
