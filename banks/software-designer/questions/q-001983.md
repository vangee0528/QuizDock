# 真题-q-001983

## 题目

对于一个 `n` 阶的对称矩阵 `A`，将其下三角区域（含主对角线）的元素按行存储在一维数组中，设元素 `A[i][y]` 存放在 `S[k]` 中，且 `i >= y`，并且 `S[1] = A[0][0]`，则 `k` 与 `i`、`y` 的对应关系是（ ）。

## 选项

- **A.** `k = i(i + 1) / 2 + y - 1`

- **B.** `k = i(i + 1) / 2 + y + 1`

- **C.** `k = i(i - 1) / 2 + y + 1`

- **D.** `k = i(i - 1) / 2 + y - 1`

## 参考答案

- **B.** `k = i(i + 1) / 2 + y + 1`
