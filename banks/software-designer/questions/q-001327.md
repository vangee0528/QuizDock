# 真题-q-001327

## 题目

采用面向对象方法进行某游戏设计，游戏中有野鸭、红头鸭等各种鸭子边游泳戏水边呱呱叫，不同种类的鸭子具有不同颜色，设计鸭子类负责呱呱叫和游泳方法的实现显示颜色设计为抽象方法，由野鸭和红头鸭各自具体实现，这一机制称为_（1）_。当给这些类型的一组不同对象发送同一显示颜色消息时，能实现各自显示自己不同颜色的结果，这种现象称为 （请作答此空）

## 选项

- **A.** 覆盖

- **B.** 重载

- **C.** 动态绑定

- **D.** 多态

## 参考答案

- **D.** 多态
