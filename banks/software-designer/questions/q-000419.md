# 操作系统-q-000419

## 题目

在单处理机系统中，采用先来先服务调度算法。系统中有四个进程，p1、p2、p3、P4（假设进程按此顺序到达）其中p1为运行状态，p2为就绪状态，p3和p4为等待状态，且p3等待打印机，p4等待扫描仪，若p1 （请作答此空） 。则p1、p2、p3和p4的状态应分别为 （2） 。

## 选项

- **A.** （7）时间片到

- **B.** （7）释放了扫描仪

- **C.** （7）释放了打印机

- **D.** （7）已完成

## 参考答案

- **C.** （7）释放了打印机
