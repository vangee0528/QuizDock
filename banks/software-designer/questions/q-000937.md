# 软件工程-q-000937

## 题目

用例从用户角度描述系统的行为。用例之间可以存在一定的关系。在“某图书馆管理系统”用例模型中，所有用户使用系统之前必须通过“身份验证”。“身份验证”可以有“密码验证”和“智能卡验证”两种方式。“身份验证”、“密码验证”和“智能卡验证”之间是（ ）关系。

## 选项

- **A.** 关联

- **B.** 包含

- **C.** 扩展

- **D.** 泛化

## 参考答案

- **D.** 泛化
