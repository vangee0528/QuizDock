# 真题-q-001124

## 题目

在支持多线程的操作系统中，假设进程 P 创建了线程 TI、T2 和 T3，那么以下叙述中错误 的是（28）。

## 选项

- **A.** 线程 T1、T2 和 T3 可以共享进程 P 的代码

- **B.** 线程 T1、T2 可以共享 P 进程中 T3 的栈指针

- **C.** 线程 T1、T2 和 T3 可以共享进程 P 打开的文件

- **D.** 线程 T1、T2 和 T3 可以共享进程 P 的全局变量

## 参考答案

- **B.** 线程 T1、T2 可以共享 P 进程中 T3 的栈指针
