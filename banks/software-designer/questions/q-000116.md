# 程序设计语言-q-000116

## 题目

下列关于一个类的静态成员的描述中，不正确的是（）。

## 选项

- **A.** 该类的对象共享其静态成员变量的值

- **B.** 静态成员变量可被该类的所有方法访问

- **C.** 该类的静态方法只能访问该类的静态成员变量

- **D.** 该类的静态数据成员变量的值不可修改

## 参考答案

- **D.** 该类的静态数据成员变量的值不可修改
