# 真题-q-001855

## 题目

某公司数据库的两个关系为：部门(部门号，部门名，负责人，电话)和员工(员工号，姓名，住址)。假设每个部门有若干名员工，一名负责人，一部电话；员工号为员工关系的主键。
若部门名是唯一的，请将下述SQL语句的空缺部分补充完整。
CREATE TABLE 部门 (部门号 CHAR60　PRIMARY KEY，
部门名 CHAR61　 （请作答此空）  ,
负责人CHAR62,
电话CHAR63)
  （2）  ;

## 选项

- **A.** NOT NULL

- **B.** UNIQUE

- **C.** KEY UNIQUE

- **D.** PRIMARY KEY

## 参考答案

- **B.** UNIQUE
