# 计算机网络-q-000609

## 题目

帧中继作为一种远程接入方式有许多优点，下面的选项中错误的是（　）。

## 选项

- **A.** 帧中继比X.25的通信开销少，传输速度更快

- **B.** 帧中继与DDN相比，能以更灵活的方式支持突发式通信

- **C.** 帧中继比异步传输模式能提供更高的数据速率

- **D.** 租用帧中继虚电路比租用DDN专线的费用低

## 参考答案

- **C.** 帧中继比异步传输模式能提供更高的数据速率
