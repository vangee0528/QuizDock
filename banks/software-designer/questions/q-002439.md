# 真题-q-002439

## 题目

在操作系统中，引入缓冲技术的主要目的是（ ）。

## 选项

- **A.** 提高CPU的运算速度

- **B.** 缓和CPU与I/O设备之间速度不匹配的矛盾

- **C.** 扩大主存的存储容量

- **D.** 提供主存与辅存之间的接口

## 参考答案

- **B.** 缓和CPU与I/O设备之间速度不匹配的矛盾
