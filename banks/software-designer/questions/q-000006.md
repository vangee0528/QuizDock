# 计算机基础-q-000006

## 题目

计算机在执行一个指令的过程中，需要直接寻址，首先要将 （1） 的值送到地址总线上。

## 选项

- **A.** 指令寄存器（IR）

- **B.** 通用寄存器（GR）

- **C.** 累加器（AC）

- **D.** 程序计数器（PC）

## 参考答案

- **D.** 程序计数器（PC）
