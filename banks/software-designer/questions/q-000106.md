# 程序设计语言-q-000106

## 题目

下面 C 程序段中 `count++` 语句执行的次数为（）。

```c
for (int i = 1; i <= 11; i *= 2)
    for (int j = 1; j <= i; j++)
        count++;
```

## 选项

- **A.** 15

- **B.** 16

- **C.** 31

- **D.** 32

## 参考答案

- **A.** 15
