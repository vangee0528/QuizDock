# 真题-q-001626

## 题目

对于两个并发进程，设互斥信号量为m（初值为1），若m=0，则（ ）。

## 选项

- **A.** 表示没有进程进入临界区

- **B.** 表示有一个进程进入临界区

- **C.** 表示有一个进程进入临界区，另一个进程等待进入

- **D.** 表示两个进程进入临界区

## 参考答案

- **B.** 表示有一个进程进入临界区
