# 数据结构与算法-q-000273

## 题目

具有n个顶点、e条边的图采用邻接表存储结构，进行深度优先遍历和广度优先遍历运算的时间复杂度均为（）。

## 选项

- **A.** O(n^2)

- **B.** O(e^2)

- **C.** O(n*e)

- **D.** O(n+e)

## 参考答案

- **D.** O(n+e)
