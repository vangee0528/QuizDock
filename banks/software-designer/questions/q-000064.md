# 计算机基础-q-000064

## 题目

硬磁盘存储器的道存储密度是指（ ），而不同磁道上的位密度是（作答此空）。

## 选项

- **A.** 靠近圆心的密度大

- **B.** 靠近外边沿的密度大

- **C.** 靠近圆心的密度小

- **D.** 靠近半径中间的密度小

## 参考答案

- **A.** 靠近圆心的密度大
