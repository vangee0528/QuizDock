# 数据结构与算法-q-000204

## 题目

设有栈S和队列Q且其初始状态为空，数据元素序列a,b,c,d,e,f依次通过栈S，且各个元素从S出栈后立即进入队列Q，若出队列的序列是b,d,f,e,c,a，则S中的元素最多时，栈底到栈顶的元素依次为（）。

## 选项

- **A.** a,b,c

- **B.** a,c,d

- **C.** a,c,e,f

- **D.** a,d,f,e

## 参考答案

- **C.** a,c,e,f
