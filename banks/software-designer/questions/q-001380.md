# 真题-q-001380

## 题目

已知文法G：S->A0|B1, a->S1|1，b->S0|0，其中S是开始符号。从S出发可以推导出（）。

## 选项

- **A.** 所有由0构成的字符串

- **B.** 所有由1构成的字符串

- **C.** 某些0和1相等的字符串

- **D.** 所有0和1个数不同的字符串

## 参考答案

- **C.** 某些0和1相等的字符串
