# 真题-q-001437

## 题目

PKI 体系中，由 SSL/TLS 实现 HTTPS 应用。浏览器和服务器之间用于加密 HTTP 消息的方式是（请作答此空）。如果服务器证书被撤销，那么所产生的后果是客户端无法再信任服务器。

## 选项

- **A.** 对方公钥+公钥加密

- **B.** 本方公钥+公钥加密

- **C.** 会话密钥+公钥加密

- **D.** 会话密钥+对称加密

## 参考答案

- **D.** 会话密钥+对称加密
