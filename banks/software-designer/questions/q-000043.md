# 计算机基础-q-000043

## 题目

以下关于 RISC 和 CISC 的叙述中，不正确的是（）。

## 选项

- **A.** RISC 的大多数指令在一个时钟周期内完成

- **B.** RISC 普遍采用硬布线控制器，CISC 则普遍采用微程序控制器

- **C.** RISC 的指令种类和寻址方式相对于 CISC 更少

- **D.** RISC 和 CISC 都可以采用流水线技术

## 参考答案

- **B.** RISC 普遍采用硬布线控制器，CISC 则普遍采用微程序控制器
