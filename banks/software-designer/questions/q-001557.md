# 真题-q-001557

## 题目

循环冗余校验码（CRC）利用生成多项式进行编码。设数据位为n,校验位为k位，则CRC码的格式为(  )。

## 选项

- **A.** k个校验位按照指定间隔位与n个数据位混淆

- **B.** k个校验位之后跟n个数据位

- **C.** n个数据位之后跟k个校验位

- **D.** k个校验位等间隔的放入n个数据位中

## 参考答案

- **C.** n个数据位之后跟k个校验位
