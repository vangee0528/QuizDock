# 真题-q-001202

## 题目

对数组A=（2,8,7,1,3,5,6,4）构建大顶堆为（62）（用数组表示）。

## 选项

- **A.** (1,2,3,4,5,6,7,8)

- **B.** (1,2,5,4,3,7,6,8)

- **C.** (8,4,7,2,3,5,6,1).

- **D.** (8,7,6,5,4,3,2,1)

## 参考答案

- **C.** (8,4,7,2,3,5,6,1).
