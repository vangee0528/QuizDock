# 操作系统-q-000418

## 题目

假设系统中有n个进程共享3台打印机，任一进程在任一时刻最多只能使用1台打印机。若用PV操作控制n个进程使用打印机，则相应信号量s的取值范围为（请作答此空）；若信号量S的值为-3，则系统中有（）个进程等待使用打印机。

## 选项

- **A.** 0，-1，…，-(n-1)

- **B.** 3，2，1，0，-1，…，-(n-3)

- **C.** 1，0，-1，…，-(n-1)

- **D.** 2，1，0，-1，…，-(n-2)

## 参考答案

- **B.** 3，2，1，0，-1，…，-(n-3)
