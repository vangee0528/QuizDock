# 操作系统-q-000418

## 题目

假设系统中有 n 个进程共享 3 台打印机，任一进程在任一时刻最多只能使用 1 台打印机。若用 PV 操作控制 n 个进程使用打印机，则相应信号量 S 的取值范围为（请作答此空）；若信号量 S 的值为 -3，则系统中有（ ）个进程等待使用打印机。

## 选项

- **A.** 0，-1，…，-(n-1)

- **B.** 3，2，1，0，-1，…，-(n-3)

- **C.** 1，0，-1，…，-(n-1)

- **D.** 2，1，0，-1，…，-(n-2)

## 参考答案

- **B.** 3，2，1，0，-1，…，-(n-3)
