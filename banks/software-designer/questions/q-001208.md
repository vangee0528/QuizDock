# 真题-q-001208

## 题目

以下Windows系统中，用于清除本地DNS缓存的命令是（）。

## 选项

- **A.** ipconfig / release

- **B.** ipconfig /flushdns

- **C.** ipconfig /displaydns

- **D.** ipconfig / registerdns

## 参考答案

- **B.** ipconfig /flushdns
