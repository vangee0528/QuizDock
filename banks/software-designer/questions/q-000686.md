# 软件工程-q-000686

## 题目

美国卡内基—梅隆大学SEI提出的CMM模型将软件过程的成熟度分为5个等级，以下选项中，属于可管理级的特征是（ ）。

## 选项

- **A.** 工作无序，项目进行过程中经常放弃当初的计划

- **B.** 建立了项目级的管理制度

- **C.** 建立了企业级的管理制度

- **D.** 软件过程中活动的生产率和质量是可度量的

## 参考答案

- **D.** 软件过程中活动的生产率和质量是可度量的
