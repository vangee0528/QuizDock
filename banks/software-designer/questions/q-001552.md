# 真题-q-001552

## 题目

在29个元素构成的查找表中查找任意一个元素时，可保证最多与表中5个元素进行比较即可确定查找结果，则采用的查找表及查找方法是(  )。

## 选项

- **A.** 二叉排序树上的查找

- **B.** 顺序表上的顺序查找

- **C.** 有序顺序表上的二分查找

- **D.** 散列表中的哈希查找

## 参考答案

- **C.** 有序顺序表上的二分查找
