# 真题-q-001213

## 题目

股票交易中，股票代理(Broker) 根据客户发出的股票操作指示进行股票的买卖操作，设计如下所示类图。该设计采用(44)模式将一个请求封装为一个对象，从而使得以用不同的请求对客户进行参数化；对请求排队或记录请求日志，以及支持可撤销的操作，其中，(45)声明执行操作的接口。该模式属于（请作答此空）模式，该模式适用于：(47)_。

![题目图片](../assets/3ce768fc93a3bb9dc80817f4cfbe93b7e8f39e484f3174426453e3a60c76883f.webp)

## 选项

- **A.** 结构类型

- **B.** 结构型对象

- **C.** 创建类型

- **D.** 行为型对象

## 参考答案

- **D.** 行为型对象
