# 操作系统-q-000463

## 题目

某计算机系统的字长为128位，磁盘的容量为2048GB，物理块的大小为8MB。假设文件管理系统采用位示图（bitmap）法记录该计算机系统磁盘的使用情况，那么位示图的大小需要（）个字。

## 选项

- **A.** 1024

- **B.** 2048

- **C.** 4096

- **D.** 8192

## 参考答案

- **B.** 2048
