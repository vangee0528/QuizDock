# 真题-q-001360

## 题目

以下关于冯诺依曼计算机的叙述中，不正确的是 ( 1 )  。

## 选项

- **A.** 程序指令和数据都采用二进制表示

- **B.** 程序指令总是存储在主存中，而数据则存储在高速缓存中

- **C.** 程序的功能都由中央处理器（CPU）执行指令来实现

- **D.** 程序的执行过程由指令进行自动控制

## 参考答案

- **B.** 程序指令总是存储在主存中，而数据则存储在高速缓存中
