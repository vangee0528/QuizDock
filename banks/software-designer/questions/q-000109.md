# 程序设计语言-q-000109

## 题目

表达式“(a+b)* (c-d)”的后缀表示为（）。

## 选项

- **A.** `a b + c d − ×`

- **B.** `a b c d + − ×`

- **C.** `a b × c d −`

- **D.** `a b c d × −`

## 参考答案

- **A.** `a b + c d − ×`
