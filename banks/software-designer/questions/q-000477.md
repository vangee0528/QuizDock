# 数据库-q-000477

## 题目

建立一个供应商、零件数据库。其中“供应商”表S(Sno，Sname，Zip，City)中的元素分别表示供应商代码、供应商名、供应商邮编、供应商所在城市，其函数依赖为：Sno→(Sname，Zip，City)，Zip→City。
a. “供应商”表S属于（ ）。
b. 若要求：供应商代码不能为空且值唯一，供应商名也唯一；零件号不能为空且值唯一；一个供应商可以供应多种零件，而一种零件可以由多个供应商供应，请补全下面 SQL 中标出的约束：

```sql
CREATE TABLE S (
  Sno   CHAR(长度) 【本题作答处】,
  Sname CHAR(长度) UNIQUE,
  Zip   CHAR(长度),
  City  CHAR(长度)
);
```

## 选项

- **A.** FOREIGN KEY

- **B.** NOT NULL UNIQUE

- **C.** FOREIGNKEY（Sno）

- **D.** PRIMARY KEY（Sname）

## 参考答案

- **B.** NOT NULL UNIQUE
