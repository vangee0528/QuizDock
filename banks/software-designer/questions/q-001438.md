# 真题-q-001438

## 题目

PKI 体系中，由 SSL/TLS 实现 HTTPS 应用。浏览器和服务器之间用于加密 HTTP 消息的方式是“会话密钥 + 对称加密”。如果服务器证书被撤销，那么所产生的后果是（请作答此空）。

## 选项

- **A.** 服务器不能执行加解密

- **B.** 服务器不能执行签名

- **C.** 客户端无法再信任服务器

- **D.** 客户端无法发送加密信息给服务器

## 参考答案

- **C.** 客户端无法再信任服务器
