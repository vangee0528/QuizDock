# 真题-q-001438

## 题目

PKI体系中，由SSL/TLS实现HTTPS应用。浏览器和服务器之间用于加密HTTP消息的方式是会话密钥+对称加密。如果服务器证书被撤销，那么所产生的后果是（请作答此空）。

## 选项

- **A.** 服务器不能执行加解密

- **B.** 服务器不能执行签名

- **C.** 客户端无法再信任服务器

- **D.** 客户端无法发送加密信息给服务器

## 参考答案

- **C.** 客户端无法再信任服务器
