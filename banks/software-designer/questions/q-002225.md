# 真题-q-002225

## 题目

某递归算法的时间复杂度计算公式为T（n）=4T （n/2）+nlgn，其中n为问题规模，则该算法的时间复杂度是（ ）。

## 选项

- **A.** O(nlgn)

- **B.** O(n^3)

- **C.** O(n^2)

- **D.** O(n^2lgn)

## 参考答案

- **C.** O(n^2)
