# 真题-q-001532

## 题目

【学员回忆版】利用报文摘要算法生成报文摘要的目的是(  )。

## 选项

- **A.** 防止发送的报文被篡改

- **B.** 对传输数据进行加密，防止数据被窃听

- **C.** 验证通信对方的身份，防止假冒

- **D.** 防止发送方否认发送过的数据

## 参考答案

- **A.** 防止发送的报文被篡改
