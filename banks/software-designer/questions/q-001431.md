# 真题-q-001431

## 题目

在由高速缓存，主存和硬盘构成的三级存储体系中，CPU执行指令时需要读取数据，那么DMA控制器和中断cpu发出的数据地址是（2）。

## 选项

- **A.** 高速缓存地址

- **B.** 主存物理地址

- **C.** 硬盘的扇区地址

- **D.** 虚拟地址

## 参考答案

- **B.** 主存物理地址
