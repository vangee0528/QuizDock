# 计算机网络-q-000640

## 共用题干

HTTP 协议采用（1）为客户端持久保持数据提供了方便，但该方式也存在一定弊端。下列选项中，不属于它的弊端的是（2）。

## 各空选项

### 第 1 空

- **A.** SSL

- **B.** Cookie

- **C.** Refer

- **D.** Agent

### 第 2 空

- **A.** 增加流量消耗

- **B.** 明文传输，存在安全性隐患

- **C.** 存在敏感信息泄漏风险

- **D.** 保存访问站点的缓存数据

## 参考答案

- 第 1 空：**B.** Cookie

- 第 2 空：**D.** 保存访问站点的缓存数据
