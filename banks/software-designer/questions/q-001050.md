# 软件工程-q-001050

## 题目

（  ）设计模式定义了对象间的一种一对多的依赖关系，以便当一个对象的状态发生改变时，所有依赖于它的对象都得到通知并自动刷新。

## 选项

- **A.** Adapter（适配器）

- **B.** Iterator（迭代器）

- **C.** Prototype（原型）

- **D.** Observer（观察者）

## 参考答案

- **D.** Observer（观察者）
