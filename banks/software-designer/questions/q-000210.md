# 数据结构与算法-q-000210

## 题目

最大子段和问题描述为：在 n 个整数（包含负数）的数组 A 中，求元素之和最大的非空连续子数组。如数组 A=(-2，11，-4，13，-5，-2)，其子数组 B=(11，-4，13) 具有最大子段和 20（11−4+13=20）。求解该问题时，可以将数组分为两个各含 n/2 个整数的子数组；最大子段和或者在前半段，或者在后半段，或者跨越中间元素。通过该方法继续划分问题，直至最后求出最大子段和，该算法的时间复杂度为（）。

## 选项

- **A.** O(n log n)

- **B.** O(n^2)

- **C.** O(n² log n)

- **D.** O(n^3)

## 参考答案

- **A.** O(n log n)
