# 数据库-q-000558

## 题目

给定关系模式R(U,F),其中U为属性集，F是U上的一组函数，下列正确的是（）

## 选项

- **A.** 若Y∈X∈U，则Y→X为F所蕴涵

- **B.** 若X→Y，Y→Z、则X→Y为F所蕴涵

- **C.** 若X→Y，Y∈Z，则X→Z为F所蕴涵

- **D.** 若X→Y，X→Z，则X→YZ为F所蕴涵

## 参考答案

- **D.** 若X→Y，X→Z，则X→YZ为F所蕴涵
