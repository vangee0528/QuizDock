# 数据库-q-000562

## 题目

设关系模式R（A, B, C），传递依赖指的是 （） ；下列结论错误的是 （作答此空） 。

## 选项

- **A.** 若A→BC，则A→B，A→C

- **B.** 若A→B，A→C，则A→BC

- **C.** 若A→C，则AB→C

- **D.** 若AB→C，则A→C，B→C

## 参考答案

- **D.** 若AB→C，则A→C，B→C
