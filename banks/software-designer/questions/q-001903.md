# 真题-q-001903

## 题目

两个串相等的充分必要条件是（ ） 。

## 选项

- **A.** 两个串长度相等

- **B.** 两个串所包含的字符集合相等

- **C.** 两个串长度相等且对应位置的字符相等

- **D.** 两个串长度相等且所包含的字符集合相等

## 参考答案

- **C.** 两个串长度相等且对应位置的字符相等
