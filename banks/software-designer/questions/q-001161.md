# 真题-q-001161

## 题目

根据渐进分析，表达式序列∶n^4，lgn，2^n，1000n，n^(2/3)，n!从低到高排序为（65）。

## 选项

- **A.** lg n, 1000n, n^(2/3), n^4, n!, 2^n

- **B.** n^(2/3), 1000n, lg n, n^4, n!, 2^n

- **C.** lg n, n^(2/3), 1000n, 2^n, n^4, n!

- **D.** lg n, n^(2/3), 1000n, n^4, 2^n, n!

## 参考答案

- **D.** lg n, n^(2/3), 1000n, n^4, 2^n, n!
