# 数据结构与算法-q-000221

## 题目

设一个包含 N 个顶点、E 条边的简单有向图采用邻接矩阵存储结构（矩阵元素 A[i][j] 等于 1/0 分别表示顶点 i 与顶点 j 之间有/无弧），则该矩阵的元素数目为（请作答此空），其中非零元素数目为（ ）。

## 选项

- **A.** E^2

- **B.** N^2

- **C.** N^2-E^2

- **D.** N^2+E^2

## 参考答案

- **B.** N^2
