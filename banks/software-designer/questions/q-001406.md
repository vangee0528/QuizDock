# 真题-q-001406

## 题目

(  46 )  设计模式能使一个对象的状态发生改变时通知所有依赖它的监听者。  （请作答此空）  设计模式限制类的实例对象只能有一个。

## 选项

- **A.** 原型(prototype)

- **B.** 工厂方法(factory method)

- **C.** 单例( singleton)

- **D.** 生成器(builder)

## 参考答案

- **C.** 单例( singleton)
