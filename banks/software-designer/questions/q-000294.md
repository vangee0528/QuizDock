# 数据结构与算法-q-000294

## 题目

类比二分搜索算法，设计k分搜索算法（k为大于2的整数）如下：首先检查n/k处（n为被搜索集合的元素个数）的元素是否等于要搜索的值，然后检查2n/k处的元素，…，这样，或者找到要搜索的元素，或者把集合缩小到原来的1/k；如果未找到要搜索的元素，则继续在得到的集合上进行k分搜索；如此进行，直到找到要搜索的元素或搜索失败。此k分搜索算法在最坏情况下搜索成功的时间复杂度为（ ），在最好情况下搜索失败的时间复杂度为（作答此空）。

## 选项

- **A.** O(logn)

- **B.** O(nlogn)

- **C.** O(logkn)

- **D.** O(nlogkn)

## 参考答案

- **C.** O(logkn)
