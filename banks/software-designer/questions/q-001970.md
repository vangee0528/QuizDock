# 真题-q-001970

## 题目

在C/C++程序中，若函数fun无返回值、无参数，对该函数的正确声明是()。

## 选项

- **A.** void fun(void, ... )

- **B.** void fun(...).

- **C.** fun(void);

- **D.** void fun(void);

## 参考答案

- **D.** void fun(void);
