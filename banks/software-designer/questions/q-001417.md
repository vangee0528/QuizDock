# 真题-q-001417

## 题目

对长度为n的有序顺序进行折半查找（即二分查找）的过程可用一棵判定树表示，该判定树的形态符合  (  58 )  的特点。

## 选项

- **A.** 最优二叉树（即哈夫曼树）

- **B.** 平衡二叉树

- **C.** 完全二叉树

- **D.** 最小生成树

## 参考答案
