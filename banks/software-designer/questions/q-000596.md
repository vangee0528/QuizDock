# 数据库-q-000596

## 题目

已知关系模式：图书(图书编号，图书类型，图书名称，作者，出版社，出版日期，ISBN)，图书编号唯一标识一本图书。建立“计算机”类图书的视图Computer-BOOK，并要求进行修改、插入操作时保证该视图只有计算机类的图书。实现上述要求的SQL语句如下：
CREATE （1）
    AS SELECT 图书编号, 图书名称, 作者, 出版社, 出版日期
       FROM 图书
       WHERE 图书类型='计算机'
       （请作答此空）;

## 选项

- **A.** FOR ALL

- **B.** PUBLIC

- **C.** WITH CHECK OPTION

- **D.** WITH GRANT OPTION

## 参考答案

- **C.** WITH CHECK OPTION
