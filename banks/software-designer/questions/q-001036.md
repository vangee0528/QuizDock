# 软件工程-q-001036

## 题目

（  ）设计模式能使一个对象的状态发生改变时通所有依赖它的监听者。（作答此空）设计模式限制类的实例对象只能由一个。

## 选项

- **A.** 原型（prototype）

- **B.** 工厂方法（factorymethod）

- **C.** 单例（singleton）

- **D.** 生成器（builder）

## 参考答案

- **C.** 单例（singleton）
