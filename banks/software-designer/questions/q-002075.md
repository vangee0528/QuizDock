# 真题-q-002075

## 题目

## 选项

- **A.** 有1个候选码A

- **B.** 有1个候选码CE

- **C.** 有2个候选码AC和AE

- **D.** 有2个候选码CE和AC

## 参考答案

- **B.** 有1个候选码CE
