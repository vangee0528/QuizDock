# 操作系统-q-000410

## 题目

对于两个并发进程，设互斥信号量 S（初始值为 1），若 S=-1，则（ ）。

## 选项

- **A.** 表示没有进程进入临界区

- **B.** 表示有一个进程进入临界区

- **C.** 表示有一个进程进入临界区，另一个进程等待进入

- **D.** 表示有两个进程进入临界区

## 参考答案

- **C.** 表示有一个进程进入临界区，另一个进程等待进入
