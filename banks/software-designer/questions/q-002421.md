# 真题-q-002421

## 题目

关于职务发明创造的专利权归属，以下说法正确的是 （ ） 。

## 选项

- **A.** 应归属于发明人个人

- **B.** 应归属于发明人所在的单位

- **C.** 可以通过合同约定由发明人个人所有

- **D.** 由国务院专利行政部门决定

## 参考答案

- **B.** 应归属于发明人所在的单位
