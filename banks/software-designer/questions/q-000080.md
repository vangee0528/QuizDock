# 计算机基础-q-000080

## 题目

设集合 Z₍₂₆₎={0,1,…,25}，乘法密码的加密函数为 Eₖ: Z₍₂₆₎→Z₍₂₆₎，Eₖ(i)=(ki) mod 26，密钥 k∈Z₍₂₆₎ \ {0}。则加密函数 E₇(i)=(7i) mod 26 是一个（ ）函数。

## 选项

- **A.** 单射但非满射

- **B.** 满射但非单射

- **C.** 非单射且非满射

- **D.** 双射

## 参考答案

- **D.** 双射
