# 数据库-q-000572

## 题目

假定某企业2014年5月的员工工资如下表所示：

查询人数大于2的部门和部门员工应发工资的平均工资的SQL语句如下：
SELECT （ ）
FROM工资表
（ ）
（请作答此空）；

![题目图片](../assets/6b2a6ef0dc09c4ef80cf8a2edcf837f0e43d65c6c0faf14ec15f9fc19278c189.png)

## 选项

- **A.** WHERE COUNT(姓名)>2

- **B.** WHERE COUNT(DISTINCT(部门))>2

- **C.** HAVING COUNT(姓名)>2

- **D.** HAVING COUNT(DISTINCT(部门))>2

## 参考答案

- **C.** HAVING COUNT(姓名)>2
