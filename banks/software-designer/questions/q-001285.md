# 真题-q-001285

## 题目

n个关键码构成的序列{k1，k2, ...kn,}当且仅当满足下列关系时称其为堆。
{
  k_i ≤ k2i
  k_i ≤ k2i+1
}或
ki≥k2i，ki≥k2i+1
以下关键码序列中，(60) 不是堆。

## 选项

- **A.** 15,25, 21,53,73, 65,33

- **B.** 15,25, 21,33, 73, 65,53

- **C.** 73, 65, 25, 21, 15,53, 33

- **D.** 73, 65, 25,33, 53,15, 21

## 参考答案

- **C.** 73, 65, 25, 21, 15,53, 33
