# 真题-q-001285

## 题目

`n` 个关键码构成的序列 `{k₁, k₂, …, kₙ}`，当且仅当满足下列关系时称其为堆：对所有满足 `2i ≤ n` 或 `2i + 1 ≤ n` 的 `i`，有 `kᵢ ≤ k₂ᵢ`、`kᵢ ≤ k₂ᵢ₊₁`，或有 `kᵢ ≥ k₂ᵢ`、`kᵢ ≥ k₂ᵢ₊₁`。以下关键码序列中，（60）不是堆。

## 选项

- **A.** 15,25, 21,53,73, 65,33

- **B.** 15,25, 21,33, 73, 65,53

- **C.** 73, 65, 25, 21, 15,53, 33

- **D.** 73, 65, 25,33, 53,15, 21

## 参考答案

- **C.** 73, 65, 25, 21, 15,53, 33
