# 真题-q-001415

## 题目

一个高度为 `k` 的满二叉树的结点总数为 `2^k - 1`。从根结点开始，自上而下、同层次结点从左至右，对结点按照顺序依次编号，即根结点编号为 1，其左、右孩子结点编号分别为 2 和 3，再下一层从左到右的编号为 4、5、6、7，依次类推。那么，在一棵满二叉树中，对于编号为 `m` 和 `n` 的两个结点，若 `n = 2m + 1`，则（56）结点。

## 选项

- **A.** m是n的左孩子

- **B.** m是n的右孩子

- **C.** n是m的左孩子

- **D.** n是m的右孩子

## 参考答案

- **D.** n是m的右孩子
