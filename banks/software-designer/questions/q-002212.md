# 真题-q-002212

## 题目

用数据流图对某医院挂号系统如下需求进行建模：
（1）患者通过终端提交挂号请求；
（2）系统验证患者信息；
（3）系统生成挂号单，并存储到挂号记录。
以下（请作答此空）不是数据流。

## 选项

- **A.** 挂号请求

- **B.** 患者信息

- **C.** 挂号记录

- **D.** 挂号单

## 参考答案

- **C.** 挂号记录
