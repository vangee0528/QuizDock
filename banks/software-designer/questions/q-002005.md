# 真题-q-002005

## 题目

模块A提供某个班级某门课程的成绩给模块B，模块B计算平均成绩、最高分和最低分，将计算结果返回给模块A，则模块B在软件结构图中属于 （ ） 模块。

## 选项

- **A.** 传入

- **B.** 传出

- **C.** 变换

- **D.** 协调

## 参考答案

- **C.** 变换
