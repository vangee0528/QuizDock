# 真题-q-002230

## 题目

对n阶上三角矩阵A按行压缩存储，将元素A （0≤i,j<n且i≤j）存储在B[k] （k≥1） 中，则k的值为（）。

## 选项

- **A.** -i^2/2+(n+1/2)i+j-n

- **B.** -i^2/2+(n+1/2)i+j-1

- **C.** -i^2/2+(n-1/2)i+j

- **D.** -i^2/2+(n-1/2)i+j+1

## 参考答案

- **D.** -i^2/2+(n-1/2)i+j+1
