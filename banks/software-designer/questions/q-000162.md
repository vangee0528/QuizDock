# 程序设计语言-q-000162

## 题目

把数式 a + b/(2a) 写成 Python 语言的表达式，下列书写正确的是（）。

## 选项

- **A.** ab2a/+

- **B.** ab+2a/

- **C.** a+b/2*a

- **D.** `a + b / (2 * a)`

## 参考答案

- **D.** `a + b / (2 * a)`
