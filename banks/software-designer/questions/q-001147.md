# 真题-q-001147

## 题目

某高校信息系统设计的分 E-R 图中，人力部门定义的职工实体具有属性：职工号、姓名、 性别和出生日期；教学部门定义的教师实体具有属性：教师号、姓名和职称。这种情况属于 （请作答此空），在合并 E-R 图时，（2）解决这一冲突。

## 选项

- **A.** 属性冲突

- **B.** 命名冲突

- **C.** 结构冲突

- **D.** 实体冲突

## 参考答案

- **B.** 命名冲突
