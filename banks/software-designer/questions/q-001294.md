# 真题-q-001294

## 题目

●对于长度相同但格式不同的两种浮点数，假设前者阶码长、尾数短，后者阶码短。尾数长。其他规定都相同，则二者可表示数值的范围和精度情况为__（5）

## 选项

- **A.** 二者可表示的数的范围和精度相同

- **B.** 前者所表示的数的范围更大且精度更高

- **C.** 前者所表示的数的范围更大但精度更低

- **D.** 前者所表示的数的范围更小但精度更高

## 参考答案

- **C.** 前者所表示的数的范围更大但精度更低
