# 计算机基础-q-000013

## 题目

从基本的CPU工作原理来看，若CPU执行MOV R1，R0指令(即将寄存器R0的内容传送到寄存器R1中)，则CPU首先要完成的操作是 （2） (其中PC为程序计数器；M为主存储器；DR为数据寄存器；IR为指令寄存器；AR为地址寄存器)。

## 选项

- **A.** (R0)→R1

- **B.** PC→AR

- **C.** M→DR

- **D.** DR→IR

## 参考答案

- **B.** PC→AR
