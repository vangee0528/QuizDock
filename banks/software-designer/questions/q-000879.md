# 软件工程-q-000879

## 题目

下面关于面向对象方法中消息的叙述，不正确的是（ ）。

## 选项

- **A.** 键盘、鼠标、通信端口、网络等设备一有变化，就会产生消息

- **B.** 操作系统不断向应用程序发送消息，但应用程序不能向操作系统发送消息

- **C.** 应用程序之间可以相互发送消息

- **D.** 发送与接收消息的通信机制与传统的子程序调用机制不同

## 参考答案

- **B.** 操作系统不断向应用程序发送消息，但应用程序不能向操作系统发送消息
