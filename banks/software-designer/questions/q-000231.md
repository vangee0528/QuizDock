# 数据结构与算法-q-000231

## 题目

二叉树的高度是指其层数，空二叉树的高度为 0，仅有根结点的二叉树高度为 1。若某二叉树中共有 1024 个结点，则该二叉树的高度是整数区间（ ）中的任一值。

## 选项

- **A.** (10, 1024)

- **B.** [10, 1024]

- **C.** (11, 1024)

- **D.** [11, 1024]

## 参考答案

- **D.** [11, 1024]
