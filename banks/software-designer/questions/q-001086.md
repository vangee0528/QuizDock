# 法律法规与知识产权-q-001086

## 题目

关于开源软件的著作权，以下说法正确的是（）。

## 选项

- **A.** 开源软件不涉及著作权问题

- **B.** 开源软件的著作权归使用者所有

- **C.** 开源软件的著作权归开发者所有，使用者不能进行任何修改

- **D.** 开源软件的著作权归开发者所有，但使用者可以自由使用、修改和分发

## 参考答案

- **D.** 开源软件的著作权归开发者所有，但使用者可以自由使用、修改和分发
