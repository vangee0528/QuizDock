# 软件工程-q-000906

## 题目

采用面向对象设计方法开发电商平台，设计负责处理用户订单的类OrderService，它不仅处理订单创建，还负责记录订单日志和发送确认邮件。OrderService类违反了面向对象设计（ ）原则。

## 选项

- **A.** 里氏替换

- **B.** 单一职责

- **C.** 接口隔离

- **D.** 开放-封闭

## 参考答案

- **B.** 单一职责
