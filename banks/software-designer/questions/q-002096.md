# 真题-q-002096

## 题目

从 IPv4 的地址构造来看，其表达的网络地址数是有限的。现在有一个 C 类地址 `210.34.198.X`，意味着这个地址唯一标识一个物理网络，该网络最多可以有 255 个结点。但若此时有多个物理网络要表示，且每个物理网络的结点数较少，则需要采用子网划分技术，用部分主机位作为表达子网的位数。此处用主机位的前两位作为子网位，就可以区分 4 个子网。此时其对应的子网掩码是（ ）。

## 选项

- **A.** 255.255.255.256

- **B.** 255.255.255.128

- **C.** 255.255.255.198

- **D.** 255.255.255.192

## 参考答案

- **D.** 255.255.255.192
