# 真题-q-001103

## 题目

## 选项

- **A.** 加密用以确保数据的保密性

- **B.** 认证用以确保报文发送者和接收者的真实性

- **C.** 认证和加密都可以阻止对手进行被动攻击

- **D.** 身份认证的目的在于识别用户的合法性，阻止非法用户访问系统

## 参考答案

- **C.** 认证和加密都可以阻止对手进行被动攻击
