# 真题-q-001149

## 题目

假设关系 R<U，F>，U={A,B,C,D}，F=｛A→BC,AC→D,B→D｝，那么在关系 R 中（53）。

## 选项

- **A.** 不存在传递依赖，候选关键字 A

- **B.** 不存在传递依赖，候选关键字 AC

- **C.** 存在传递依赖 A→D，候选关键字 A

- **D.** 存在传递依赖 B→D，候选关键字 C

## 参考答案

- **C.** 存在传递依赖 A→D，候选关键字 A
