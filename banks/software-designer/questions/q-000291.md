# 数据结构与算法-q-000291

## 题目

对 n 个元素的有序表 A[1..n] 进行二分（折半）查找（除 2 取商时向下取整），查找元素 A[i] 时，最多与 A 中的（ ）个元素进行比较。

## 选项

- **A.** n

- **B.** [log₂n]-1

- **C.** n/2

- **D.** [log₂n]+1

## 参考答案

- **D.** [log₂n]+1
