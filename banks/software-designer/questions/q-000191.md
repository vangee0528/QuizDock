# 数据结构与算法-q-000191

## 题目

对于线性表（由n个同类元素构成的线性序列），采用单向循环链表存储的特点之一是（  ）。

## 选项

- **A.** 从表中任意结点出发都能遍历整个链表

- **B.** 对表中的任意结点可以进行随机访问

- **C.** 对于表中的任意一个结点，访问其直接前驱和直接后继结点所用时间相同

- **D.** 第一个结点必须是头结点

## 参考答案

- **A.** 从表中任意结点出发都能遍历整个链表
