# 真题-q-002052

## 题目

某个算法的时间复杂度递归式为 `T(n) = T(n - 1) + n`，其中 `n` 为问题的规模，则该算法的渐进时间复杂度为（ ）；若问题的规模增加了 16 倍，则运行时间增加（请作答此空）倍。

## 选项

- **A.** 16

- **B.** 64

- **C.** 256

- **D.** 1024

## 参考答案

- **C.** 256
