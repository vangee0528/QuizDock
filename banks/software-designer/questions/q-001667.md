# 真题-q-001667

## 题目

对一组数据2,12,16,88,5,10进行排序，如果前3趟排序结果如下：
第一趟排序结果：2,12,16,5,10,88
第二趟排序结果：2,12,5,10,16,88
第三趟排序结果：2,5,10,12,16,88
则采用的排序算法可能是（ ）

## 选项

- **A.** 冒泡排序

- **B.** 希尔排序

- **C.** 归并排序

- **D.** 基数排序

## 参考答案

- **A.** 冒泡排序
