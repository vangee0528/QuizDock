# 真题-q-001099

## 题目

以下关于两个浮点数相加运算的叙述中，正确的是（3）。

## 选项

- **A.** 首先进行对阶，阶码大的向阶码小的对齐

- **B.** 首先进行对阶，阶码小的向阶码大的对齐

- **C.** 不需要对阶，直接将尾数相加

- **D.** 不需要对阶，直接将阶码相加

## 参考答案

- **B.** 首先进行对阶，阶码小的向阶码大的对齐
