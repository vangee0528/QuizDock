# 真题-q-002173

## 题目

类是一组具有相同属性的和相同服务的对象的抽象描述，类中的每个对象都是这个类的一个（1）。类之间共享属性与服务的机制称为（请作答此空）。一个对象通过发送（3）来请求另一个对象为其服务。

## 选项

- **A.** 多态性

- **B.** 动态绑定

- **C.** 静态绑定

- **D.** 继承

## 参考答案

- **D.** 继承
