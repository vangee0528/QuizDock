# 操作系统-q-000431

## 题目

假设系统采用PV操作实现进程同步与互斥，若有n个进程共享一台扫描仪，那么当信号量S的值为-3时，表示系统中有（  ）个进程等待使用扫描仪。

## 选项

- **A.** 0

- **B.** n-3

- **C.** 3

- **D.** n

## 参考答案

- **C.** 3
