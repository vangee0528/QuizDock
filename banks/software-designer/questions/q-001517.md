# 真题-q-001517

## 题目

【学员回忆版】执行以下 Python 语句之后，列表x 为 (  )
x=[1,2,3]
x.append([4,5])

## 选项

- **A.** [1,2,3,4,5]

- **B.** [1,2,3]

- **C.** [4,5]

- **D.** [1,2,3,[4,5]]

## 参考答案

- **D.** [1,2,3,[4,5]]
