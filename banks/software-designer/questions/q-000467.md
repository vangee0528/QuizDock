# 操作系统-q-000467

## 题目

某文件系统采用位示图（bitmap）记录磁盘的使用情况。计算机系统的字长为 64 位，物理块依次编号为 0、1、2、…，位示图中的字也依次编号为 0、1、2、…。那么，16335 号物理块的使用情况在位示图中的第（）个字中描述。

## 选项

- **A.** 254

- **B.** 255

- **C.** 256

- **D.** 257

## 参考答案

- **B.** 255
