# 程序设计语言-q-000132

## 题目

设某程序中定义了全局整型变量x和r，且函数f()的定义如下所示，则在语句“x = r*r +1 ;”中 （ ） 。
int f(int r)
{int x;
x = r*r +1 ;
return x;
}

## 选项

- **A.** x和r均是全局变量

- **B.** x是全局变量、r是形式参数

- **C.** x是局部变量、r是形式参数

- **D.** x是局部变量、r是全局变量

## 参考答案

- **C.** x是局部变量、r是形式参数
