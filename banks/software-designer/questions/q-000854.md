# 软件工程-q-000854

## 题目

假设 Bird 和 Cat 是 Animal 的子类，Parrot 是 Bird 的子类，bird 是 Bird 的一个对象，cat 是 Cat 的一个对象，parrot 是 Parrot 的一个对象。以下叙述中不正确的是（请作答此空）。
假设 Animal 类中定义接口 move()，Bird、Cat 和 Parrot 分别实现自己的 move()。调用 move() 时，不同对象收到同一消息可以产生各自不同的结果，这一现象称为（2）。

## 选项

- **A.** cat和bird可看作是Animal的对象

- **B.** parrot和bird可看作是Animal的对象

- **C.** bird可以看作是Parrot的对象

- **D.** parrot可以看作是Bird的对象

## 参考答案

- **C.** bird可以看作是Parrot的对象
