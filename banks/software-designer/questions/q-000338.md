# 数据结构与算法-q-000338

## 题目

对 n 个基本有序的整数进行排序，若采用插入排序算法，则时间和空间复杂度分别为（ ）；若采用快速排序算法，则时间和空间复杂度分别为（请作答此空）。

## 选项

- **A.** O(n²) 和 O(n)

- **B.** O（nlgn）和O（n）

- **C.** O(n²) 和 O(1)

- **D.** O（nlgn）和O（1）

## 参考答案

- **A.** O(n²) 和 O(n)
