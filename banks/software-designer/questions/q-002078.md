# 真题-q-002078

## 题目

某高校信息系统釆用分布式数据库系统，该系统中“本地业务能够在本地正常进行而不依赖于其他场地的数据库”和“数据在不同场地上的存储”分别称为分布式数据库的 （ ） 。

## 选项

- **A.** 共享性和分布性

- **B.** 自治性和分布性

- **C.** 自治性和可用性

- **D.** 可用性和分布性

## 参考答案

- **B.** 自治性和分布性
