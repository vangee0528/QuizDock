# 计算机基础-q-000004

## 题目

在 CPU 中，（1）的主要功能是在控制器的控制下完成各种算术运算和逻辑运算。（请作答此空）为 ALU 提供一个工作区，用来暂存数据。（3）存储下一条要执行指令的地址。（4）用来保存当前 CPU 所访问的内存单元的地址。

## 选项

- **A.** 运算器（第二空）

- **B.** 累加寄存器（第二空）

- **C.** 程序计数器（第二空）

- **D.** 地址寄存器（第二空）

## 参考答案

- **B.** 累加寄存器（第二空）
