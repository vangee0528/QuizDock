# 真题-q-001422

## 题目

对n个基本有序的整数进行排序，若采用插入排序算法，则时间和空间复杂度分别为  (  62 )  ；若采用快速排序算法，则时间和空间复杂度分别为  （请作答此空）  。

## 选项

- **A.** O（n^2）和O（n）

- **B.** O（nlgn）和O（n）

- **C.** O（n^2）和O（1）

- **D.** O（nlgn）和O（1）

## 参考答案

- **C.** O（n^2）和O（1）
