# 真题-q-001422

## 题目

对n个基本有序的整数进行排序，若采用插入排序算法，则时间和空间复杂度分别为  (  62 )  ；若采用快速排序算法，则时间和空间复杂度分别为  （请作答此空）  。

## 选项

- **A.** `O(n^2)` 和 `O(n)`

- **B.** `O(n lg n)` 和 `O(n)`

- **C.** `O(n^2)` 和 `O(1)`

- **D.** `O(n lg n)` 和 `O(1)`

## 参考答案

- **C.** `O(n^2)` 和 `O(1)`
