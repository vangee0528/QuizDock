# 数据结构与算法-q-000212

## 题目

对于二维数组a[1..N，1..N]中的一个元素a[i，j]（1≤i，j≤N），存储在a[i，j]之前的元素个数（  ）。

## 选项

- **A.** 与按行存储或按列存储方式无关

- **B.** 在i=j时与按行存储或按列存储方式无关

- **C.** 在按行存储方式下比按列存储方式下要多

- **D.** 在按行存储方式下比按列存储方式下要少

## 参考答案

- **B.** 在i=j时与按行存储或按列存储方式无关
