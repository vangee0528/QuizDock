# 真题-q-001936

## 题目

在一个长度为n的带头结点的单链表h上，设有尾指针r，则执行（ ）操作与链表的表长有关。

## 选项

- **A.** 删除单链表中的第一个元素

- **B.** 删除单链表中的最后一个元素

- **C.** 在单链表第一个元素前插入一个新元素

- **D.** 在单链表最后一个元素后插入一个新元素

## 参考答案

- **B.** 删除单链表中的最后一个元素
