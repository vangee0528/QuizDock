# 软件工程-q-000900

## 题目

面向对象设计有 7 个主要原则。（）强调子类可以替换父类。（）要求一个对象应当对其他对象有尽可能少的了解。（请作答此空）要依赖于抽象，而不是具体实现。

## 选项

- **A.** 迪米特原则

- **B.** 开放-封闭原则

- **C.** 依赖倒置原则

- **D.** 里式替换原则

## 参考答案

- **C.** 依赖倒置原则
