# 软件工程-q-000894

## 题目

采用面向对象方法进行系统设计时，不应该强迫客户依赖于它们不用的方法，即：依赖于抽象，不要依赖于具体，同时在抽象级别不应该有对于细节的依赖。这属于（）原则。

## 选项

- **A.** 单一责任

- **B.** 开放-封闭

- **C.** 接口分离

- **D.** 里氏替换

## 参考答案

- **C.** 接口分离
