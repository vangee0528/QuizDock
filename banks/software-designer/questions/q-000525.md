# 数据库-q-000525

## 题目

若要将部门表 Demp 中 name 列的修改权限赋予用户 Ming，并允许 Ming 将该权限授予他人，实现的 SQL 语句如下：

```sql
GRANT （1） ON TABLE Demp TO Ming （请作答此空）。
```

## 选项

- **A.** FOR ALL

- **B.** CASCADE

- **C.** WITH GRANT OPTION

- **D.** WITH CHECK OPTION

## 参考答案

- **C.** WITH GRANT OPTION
