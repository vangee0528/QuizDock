# 真题-q-002325

## 题目

以下关于统一过程RUP的叙述中，不正确的是（ ）。

## 选项

- **A.** RUP是以用例和风险为驱动，以架构为中心，迭代并且增量的开发过程

- **B.** RUP定义了四个阶段，即起始、精化、构建和确认阶段

- **C.** 每次迭代都包含计划、分析、设计、构造、集成、测试以及内部和外部发布

- **D.** 每个迭代有五个核心工作流
