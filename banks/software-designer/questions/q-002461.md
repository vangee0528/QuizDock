# 真题-q-002461

## 题目

执行如下 Python 代码的结果是什么（ ）。

```python
a = [1, 2, 3, 4, 5]
a[1:4] = []
print(a)
```

## 选项

- **A.** [2, 3, 4]

- **B.** [1, 4]

- **C.** [4, 5]

- **D.** [1, 5]

## 参考答案

- **D.** [1, 5]
