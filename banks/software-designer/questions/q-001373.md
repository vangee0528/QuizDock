# 真题-q-001373

## 题目

软件著作人与被许可方签订一份软件使用许可合同。若在该合同约定的时间和地域范围内，软件权利人不得再许可任何第三人以此相同的方法使用该项软件，但软件权利人可以自己使用，则该项许可使用是  (  14 )  。

## 选项

- **A.** 独家许可使用

- **B.** 独占许可使用

- **C.** 普通许可使用

- **D.** 部分许可使用

## 参考答案

- **A.** 独家许可使用
