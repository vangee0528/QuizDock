# 真题-q-001363

## 题目

以下关于RISC和CISC的叙述中，不正确的是  ( 4 )  。

## 选项

- **A.** RISC的大多数指令在一个时钟周期内空完成

- **B.** RISC普遍采用微程序控制器，CISC则遍采用硬布线控制器

- **C.** RISC的指令种类和寻址方式相对于CISC更少

- **D.** RISC和CISC都采用流水线技术

## 参考答案

- **B.** RISC普遍采用微程序控制器，CISC则遍采用硬布线控制器
