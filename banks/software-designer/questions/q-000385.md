# 数据结构与算法-q-000385

## 题目

给定 n 个整数构成的数组 A={a₁,a₂,…,aₙ} 和整数 x，判断 A 中是否存在两个元素 ai 和 aj，使得 ai+aj=x。为了求解该问题，首先用归并排序算法对数组 A 进行从小到大排序；然后判断是否存在 ai+aj=x，具体如下列伪代码所示。则求解该问题时排序算法应用了（ ）算法设计策略，整个算法的时间复杂度为（ ）。

```text
i = 1; j = n
while i < j:
    if ai + aj == x:
        return true
    else if ai + aj > x:
        j--
    else:
        i++
return false
```

## 选项

- **A.** O(n)

- **B.** O(nlgn)

- **C.** O(n^2)

- **D.** O(lgn)

## 参考答案

- **B.** O(nlgn)
