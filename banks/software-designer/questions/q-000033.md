# 计算机基础-q-000033

## 题目

某个计算机中心有28台微机，每台微机有24个应用，每个应用占用1个端口地址，则这个计算机中心所有应用的地址总数为（ ）。

## 选项

- **A.** 24

- **B.** 28

- **C.** 52

- **D.** 672

## 参考答案

- **D.** 672
