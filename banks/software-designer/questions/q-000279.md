# 数据结构与算法-q-000279

## 题目

在有 11 个元素的有序表 A[1..11] 中进行折半查找（向下取整），查找元素 A[11] 时，被比较的元素下标依次是（ ）。

## 选项

- **A.** 6,8,10,11

- **B.** 6,9,10,11

- **C.** 6,7,9,11

- **D.** 6,8,9,11

## 参考答案

- **B.** 6,9,10,11
