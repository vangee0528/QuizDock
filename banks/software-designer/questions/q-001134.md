# 真题-q-001134

## 题目

采用面向对象方法进行系统开发时，以下与新型冠状病毒有关的对象中，存在“一般-特 殊”关系的是（38）。

## 选项

- **A.** 确诊病人和治愈病人

- **B.** 确诊病人和疑似病人

- **C.** 医生和病人

- **D.** 发热病人和确诊病人

## 参考答案

- **D.** 发热病人和确诊病人
