# 数据结构与算法-q-000185

## 题目

采用顺序表和单链表存储长度为 n 的线性序列，根据序号查找元素，其时间复杂度分别为（）。

## 选项

- **A.** O(1)、O(1)

- **B.** O(1)、O(n)

- **C.** O(n)、O(1)

- **D.** O(n)、O(n)

## 参考答案

- **B.** O(1)、O(n)
