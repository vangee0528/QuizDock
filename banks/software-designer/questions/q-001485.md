# 真题-q-001485

## 题目

如果将 Students 表的插入权限赋予用户 User1，并允许其将该权限授予他人，那么正确的 SQL 语句如下：
```sql
GRANT（55） TABLE Students TO User1（请作答此空）;
```

## 选项

- **A.** FOR ALL

- **B.** PUBLIC

- **C.** WITH GRANT OPTION

- **D.** WITH CHECK OPTION

## 参考答案

- **C.** WITH GRANT OPTION
