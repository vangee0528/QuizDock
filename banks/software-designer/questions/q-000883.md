# 软件工程-q-000883

## 题目

面向对象的测试可分为四个层次，按照由低到高的顺序，这四个层次是（ ）。

## 选项

- **A.** 类层——模板层——系统层——算法层

- **B.** 算法层——类层—模板层——系统层

- **C.** 算法层——模板层——类层——系统层

- **D.** 类层——系统层——模板层——算法层

## 参考答案

- **B.** 算法层——类层—模板层——系统层
