# 真题-q-001637

## 题目

●下列说法中正确的是（ ）。

## 选项

- **A.** 经过测试没有发现错误说明程序正确

- **B.** 测试的目标是为了证明程序没有错误

- **C.** 成功的测试是发现了迄今尚未发现的错误的测试

- **D.** 成功的测试是没有发现错误的测试

## 参考答案

- **C.** 成功的测试是发现了迄今尚未发现的错误的测试
