# 计算机基础-q-000044

## 题目

某计算机系统采用 5 级流水线结构执行指令，设每条指令的执行由取指令(2 Δt )、分析指令(1Δt )、取操作数(3Δt )、运算(1Δt )和写回结果(2Δt ) 组成， 并分别用5 个子部件完成，该流水线的执行周期为（  ） ；若连续向流水线输入10条指令，该流水线完成的时间为（  ）。

## 选项

- **A.** 46Δt

- **B.** 36Δt

- **C.** 90Δt

- **D.** 40Δt

## 参考答案

- **B.** 36Δt
