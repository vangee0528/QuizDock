# 真题-q-001528

## 题目

【学员回忆版】以下关于软件工程标准化的叙述中，不正确的是(  )。

## 选项

- **A.** 可以提高开发人员之间的沟通效率

- **B.** 有助于提高管理水平

- **C.** 有助于提高软件产品质量

- **D.** 可以提高每一位开发人员的开发技能

## 参考答案

- **D.** 可以提高每一位开发人员的开发技能
