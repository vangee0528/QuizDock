# 程序设计语言-q-000114

## 题目

以下关于类和对象的叙述中，错误的是（  ）。

## 选项

- **A.** 类是具有相同属性和服务的一组对象的集合

- **B.** 类是一个对象模板，用它仅可以产生一个对象

- **C.** 在客观世界中实际存在的是类的实例，即对象

- **D.** 类为属于该类的全部对象提供了统一的抽象描述

## 参考答案

- **B.** 类是一个对象模板，用它仅可以产生一个对象
