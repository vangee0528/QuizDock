# 真题-q-002322

## 题目

某文件系统采用多级索引结构。若磁盘块的大小为 1K 字节，每个块号占 3 字节，那么采用二级索引时的文件最大长度为（ ）K字节。

## 选项

- **A.** 1024

- **B.** 2048

- **C.** 116281

- **D.** 232562

## 参考答案

- **C.** 116281
