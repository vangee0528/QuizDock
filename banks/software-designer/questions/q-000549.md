# 数据库-q-000549

## 题目

某公司数据库中的元件关系模式为P（元件号，元件名称，供应商，供应商所在地，库存量），函数依赖集F如下所示：
F={元件号→元件名称，（元件号，供应商）→库存量，供应商→供应商所在地}，
元件关系的主键为 （请作答此空） ，该关系存在冗余以及插入异常和删除异常等问题。为了解决这一问题需要将元件关系分解 （2） ，分解后的关系模式可以达到 （3） 。

## 选项

- **A.** 元件号，元件名称（24）

- **B.** 元件号，供应商（24）

- **C.** 元件号，供应商所在地（24）

- **D.** 供应商，供应商所在地（24）

## 参考答案

- **B.** 元件号，供应商（24）
