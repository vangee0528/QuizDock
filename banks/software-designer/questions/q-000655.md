# 计算机网络-q-000655

## 共用题干

运行 Web 浏览器的计算机与网页所在的计算机要建立（1）连接，采用（2）协议传输网页文件。

## 各空选项

### 第 1 空

- **A.** UDP

- **B.** TCP

- **C.** IP

- **D.** RIP

### 第 2 空

- **A.** HTTP

- **B.** HTML

- **C.** ASP

- **D.** RPC

## 参考答案

- 第 1 空：**B.** TCP

- 第 2 空：**A.** HTTP
