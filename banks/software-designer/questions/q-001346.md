# 真题-q-001346

## 题目

设栈初始时为空，对于入栈序列1,2,3,……，n，这些元素经过栈之后得到出栈序列 P1，P2，P3，…，Pn。若p3=4，则p1，p2不可能的取值为__(57 )__。

## 选项

- **A.** 6,5

- **B.** 2,3

- **C.** 3,1

- **D.** 3,5

## 参考答案

- **C.** 3,1
