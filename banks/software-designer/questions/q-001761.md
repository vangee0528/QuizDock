# 真题-q-001761

## 题目

将高级语言源程序翻译成机器语言程序的过程，常引入中间代码。以下关于中间代码的叙述中，不正确的是 （ ） 。

## 选项

- **A.** 中间代码不依赖于具体的机器

- **B.** 使用中间代码可提高编译程序的可移植性

- **C.** 中间代码可以用树或图表示

- **D.** 中间代码可以用栈和队列表示

## 参考答案

- **D.** 中间代码可以用栈和队列表示
