# 数据结构与算法-q-000347

## 题目

某算法的时间复杂度由递归式 T(n) = 2T(n/2) + nlogn 定义，其渐近紧致界为（ ）。

## 选项

- **A.** Θ(n)

- **B.** Θ(n log n)

- **C.** Θ(n²)

- **D.** Θ(n log²n)

## 参考答案

- **D.** Θ(n log²n)
