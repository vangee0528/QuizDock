# 程序设计语言-q-000107

## 题目

在C++语言中，若类C中定义了一个方法int f（int a，int b），那么方法（）不能与该方法同时存在于类C中。

## 选项

- **A.** int f(int x，int y)

- **B.** int f(float a，int b)

- **C.** float f(int x，float y)

- **D.** int f(int x，float y)

## 参考答案

- **A.** int f(int x，int y)
