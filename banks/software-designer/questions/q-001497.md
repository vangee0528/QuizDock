# 真题-q-001497

## 题目

在Linux 操作系统中通常使用   (  67  ) ，作为 Web 服务器，其默认的 Web站目录为  （请作答此空） 。

## 选项

- **A.** /etc/httpd

- **B.** /var/log/httpd

- **C.** /etc/home

- **D.** /home/httpd

## 参考答案

- **D.** /home/httpd
