# 计算机基础-q-000054

## 题目

以下关于 SRAM 和 DRAM 存储器的叙述中，正确的是（）。

## 选项

- **A.** 与 DRAM 相比，SRAM 集成度低、功耗大，但不需要动态刷新

- **B.** 与 DRAM 相比，SRAM 集成度高、功耗小，需要动态刷新

- **C.** 与 SRAM 相比，DRAM 集成度高、功耗大，不需要动态刷新

- **D.** 与 SRAM 相比，DRAM 集成度低、功耗大，需要动态刷新

## 参考答案

- **A.** 与 DRAM 相比，SRAM 集成度低、功耗大，但不需要动态刷新
