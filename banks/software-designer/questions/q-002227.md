# 真题-q-002227

## 题目

在软件项目团队中，成员的技能水平和协作能力差异较大，导致项目进度受阻。为提高团队整体效率，项目经理应优先考虑（ ）。

## 选项

- **A.** 重新分配团队成员任务

- **B.** 引入外部专家指导

- **C.** 增加项目奖励机制

- **D.** 开展内部技能分享与培训

## 参考答案

- **D.** 开展内部技能分享与培训
