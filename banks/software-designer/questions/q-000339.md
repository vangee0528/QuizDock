# 数据结构与算法-q-000339

## 题目

某算法的时间复杂度表达式为T(n)=an2+bnlgn+cn+d，其中，n为问题的规模，a、b、c和d为常数，用O表示其渐近时间复杂度为（  ）。

## 选项

- **A.** O(n^2)

- **B.** O(n)

- **C.** O(nlgn)

- **D.** O(1)

## 参考答案

- **A.** O(n^2)
