# 数据结构与算法-q-000205

## 题目

采用循环队列的优点是（58）。

## 选项

- **A.** 入队和出队可以在队列的同端点进行操作

- **B.** 入队和出队操作都不需要移动队列中的其他元素

- **C.** 避免出现队列满的情况

- **D.** 避免出现队列空的情况

## 参考答案

- **B.** 入队和出队操作都不需要移动队列中的其他元素
