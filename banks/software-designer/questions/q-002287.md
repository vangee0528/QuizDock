# 真题-q-002287

## 题目

在数据库事务的ACID原则中，一致性原则是指（ ）。

## 选项

- **A.** 事务必须是原子工作单元，要么全部执行，要么全部不执行

- **B.** 事务执行前后，数据库必须保持一致性状态，即满足所有预定义的完整性约束

- **C.** 多个事务并发执行时，每个事务都感觉不到其他事务的并发执行

- **D.** 事务完成之后，对数据的修改是永久性的

## 参考答案

- **B.** 事务执行前后，数据库必须保持一致性状态，即满足所有预定义的完整性约束
