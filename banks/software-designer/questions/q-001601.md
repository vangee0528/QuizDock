# 真题-q-001601

## 题目

某文件管理系统在磁盘上建立了位示图 (bitmap),记录磁盘的使用情况。 若计算机系统的字长为128位，磁盘的容量为1024 GB,物理块的大小为8MB,那么该位示图的大小为(68) 个 字 。

## 选项

- **A.** 4096

- **B.** 1024

- **C.** 2048

- **D.** 4098

## 参考答案

- **B.** 1024
