# 真题-q-001339

## 题目

在 Python 3 中，执行语句 `x = input()`，如果从键盘输入 `123` 并按回车键，则 `x` 的值为（请作答此空）。

## 选项

- **A.** `123`

- **B.** `1,2,3`

- **C.** `“1 2 3”`

- **D.** `'123'`

## 参考答案

- **D.** `'123'`
