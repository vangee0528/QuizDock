# 真题-q-001858

## 题目

UML中有4种事物：结构事物、行为事物、分组事物和注释事物。类、接口、构建属于 （1） 事物；依附于一个元素或一组元素之上对其进行约束或解释的简单符号为 （请作答此空） 事物。

## 选项

- **A.** 结构

- **B.** 行为

- **C.** 分组

- **D.** 注释

## 参考答案

- **D.** 注释
