# 真题-q-001435

## 题目

设指令流水线将一条指令的执行分为取指，分析，执行三段，已知取指时间是2ns，分析时间需2ns.执行时间为1nS，则执行完1000条指令所需时间为。（6）

## 选项

- **A.** 1004ns

- **B.** 1998ns

- **C.** 2003ns

- **D.** 2008ns

## 参考答案

- **C.** 2003ns
