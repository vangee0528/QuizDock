# 真题-q-002092

## 题目

一棵二叉树的后序遍历序列为 D、A、B、E、C，中序遍历序列为 D、E、B、A、C，则先序遍历序列为（ ）。

## 选项

- **A.** A,C,B,E,D

- **B.** D,E,C,B,A

- **C.** D,E,A,B,C

- **D.** C、E、D、B、A

## 参考答案

- **D.** C、E、D、B、A
