# 操作系统-q-000411

## 题目

在单处理机计算机系统中，有 1 台打印机、1 台扫描仪，系统采用先来先服务调度算法。假设系统中有进程 P1、P2、P3、P4，其中 P1 为运行状态，P2 为就绪状态，P3 等待打印机，P4 等待扫描仪。此时，若 P1 释放了扫描仪，则进程 P1、P2、P3、P4 的状态分别为（ ）。

## 选项

- **A.** 等待、运行、等待、就绪

- **B.** 运行、就绪、等待、就绪

- **C.** 就绪、就绪、等待、运行

- **D.** 就绪、运行、等待、就绪

## 参考答案

- **B.** 运行、就绪、等待、就绪
