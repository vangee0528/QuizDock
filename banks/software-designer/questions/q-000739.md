# 软件工程-q-000739

## 题目

在风险管理中，通常需要进行风险监测，其目的不包括(17)。

## 选项

- **A.** 消除风险

- **B.** 评估所预测的风险是否发生

- **C.** 保证正确实施了风险缓解步骤

- **D.** 收集用于后续进行风险分析的信息

## 参考答案

- **A.** 消除风险
