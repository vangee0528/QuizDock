# 真题-q-002183

## 题目

对于空栈S进行Push和Pop操作，入栈序列为a,b,c,d,e,经过Push、Push、Pop、Push、Pop、Push、Push、Pop操作后得到的出栈序列是（ ）。

## 选项

- **A.** b,a,c

- **B.** b,a,e

- **C.** b,c,a

- **D.** b,c,e

## 参考答案

- **D.** b,c,e
