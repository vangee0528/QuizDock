# 真题-q-001159

## 题目

对数组A=(2,8,7,1,3,5,6,4)用快速排序算法的划分方法进行一趟划分后得到的数组A 为（1） （非递减排序，以最后一个元素为基准元素）。进行一趟划分的计算时间为（请作答此空）。

## 选项

- **A.** O(1)

- **B.** O(lgn)

- **C.** O(n)

- **D.** O(nlgn)

## 参考答案

- **C.** O(n)
