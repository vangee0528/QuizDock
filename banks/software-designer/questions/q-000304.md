# 数据结构与算法-q-000304

## 题目

对于 n 个关键字进行堆排序，最坏情况下的时间复杂度为（ ）。

## 选项

- **A.** O(log₂ n)

- **B.** O（n）

- **C.** O(n log₂ n)

- **D.** O（n2）

## 参考答案

- **C.** O(n log₂ n)
