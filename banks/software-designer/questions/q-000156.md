# 程序设计语言-q-000156

## 题目

函数(过程)调用时，常采用传值与传地址两种方式在实参与形参间传递信息。以下叙述中，正确的是（21）。

## 选项

- **A.** 在传值方式下，将形参的值传给实参，因此，形参必须是常量或变量

- **B.** 在传值方式下，将实参的值传给形参，因此，实参必须是常量或变量

- **C.** 在传地址方式下，将形参的地址传给实参，因此，形参必须有地址

- **D.** 在传地址方式下，将实参的地址传给形参，因此，实参必须有地址

## 参考答案

- **D.** 在传地址方式下，将实参的地址传给形参，因此，实参必须有地址
