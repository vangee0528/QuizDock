# 数据结构与算法-q-000336

## 题目

某递归算法的时间复杂度计算公式为 T(n)=4T(n/2)+n log n，其中 n 为问题规模，则该算法的时间复杂度是（ ）。

## 选项

- **A.** O(n log n)

- **B.** O(n³)

- **C.** O(n²)

- **D.** O(n² log n)

## 参考答案

- **C.** O(n²)
