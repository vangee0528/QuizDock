# 真题-q-002076

## 题目

给定关系模式R（U，F），其中：属性集U = {A，B，C，D，E，G}，函数依赖集F={A→BD，C→D，E→G，G→A}。关系R中 （1） ，函数依赖集F中 （请作答此空） 。

## 选项

- **A.** 存在传递依赖，但不存在冗余函数依赖

- **B.** 既不存在传递依赖，也不存在冗余函数依赖

- **C.** 存在传递依赖，并且存在冗余函数依赖

- **D.** 不存在传递依赖，但存在冗余函数依赖

## 参考答案

- **A.** 存在传递依赖，但不存在冗余函数依赖
