# 真题-q-002309

## 题目

我国商标法规定了申请注册的商标不得使用的文字和图形，其中包括县级以上行政区的地名（文字）。以下商标注册申请，经审查，能获准注册的商标是（ ）。

## 选项

- **A.** 青岛（市）

- **B.** 黄山（市）

- **C.** 海口（市）

- **D.** 长沙（市）

## 参考答案

- **B.** 黄山（市）
