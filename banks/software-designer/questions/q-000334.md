# 数据结构与算法-q-000334

## 题目

某个算法的时间复杂度递归式T(n)=T(n-1)+n，其中n为问题的规模，则该算法的渐进时间复杂度为 （请作答此空） ，若问题的规模增加了16倍，则运行时间增加 （ ） 倍。

## 选项

- **A.** O(n)

- **B.** O(nlgn)

- **C.** O(n2)

- **D.** O(n2lgn)

## 参考答案

- **C.** O(n2)
