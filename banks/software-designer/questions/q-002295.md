# 真题-q-002295

## 题目

下列选项中，能成功创建一个Python字典的是（ ）。

## 选项

- **A.** {'a': 1, 'b': 2}

- **B.** {'a' 1, 'b' 2}

- **D.** [['a', 1], ['b', 2]]

## 参考答案
