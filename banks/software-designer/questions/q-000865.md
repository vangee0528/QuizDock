# 软件工程-q-000865

## 题目

采用面向对象开发方法时，对象是系统运行时基本实体。以下关于对象的叙述中，正确的是（33）。

## 选项

- **A.** 对象只能包括数据(属性)

- **B.** 对象只能包括操作(行为)

- **C.** 对象一定有相同的属性和行为

- **D.** 对象通常由对象名、属性和操作三个部分组成

## 参考答案

- **D.** 对象通常由对象名、属性和操作三个部分组成
