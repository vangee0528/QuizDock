# 真题-q-001342

## 题目

某高校人力资源管理系统的数据库中，教师关系模式为T(教师号，姓名，部门号，岗位，联系地址，薪资)，函数依赖集F={教师号→(姓名，部门号，岗位，联系地址)，岗位→薪资}。T关系的主键为   (52 )  ，函数依赖集F  （请作答此空）  。

## 选项

- **A.** 存在传递依赖，故关系模式T最高达到1NF

- **B.** 存在传递依赖，故关系模式T最高达到2NF

- **C.** 不存在传递依赖，故关系模式T最高达到3NF

- **D.** 不存在传递依赖，故关系模式T最高达到4NF

## 参考答案

- **B.** 存在传递依赖，故关系模式T最高达到2NF
