# 真题-q-001815

## 题目

在计算机系统中常用的输入/输出控制方式有无条件传送、中断、程序查询和DMA等。其中，采用（2）方式时，不需要CPU控制数据的传输过程。

## 选项

- **A.** 中断

- **B.** 程序查询

- **C.** DMA

- **D.** 无条件传送

## 参考答案

- **C.** DMA
