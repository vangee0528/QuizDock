# 真题-q-001257

## 题目

防火墙通常分为内网、外网和DMZ三个区域，按照受保护程度，从低到高正确的排列次序为(11)。

## 选项

- **A.** 内网、外网和DMZ

- **B.** 外网、DMZ和内网

- **C.** DMZ、内网和外网

- **D.** 内网、DMZ和外网

## 参考答案

- **B.** 外网、DMZ和内网
