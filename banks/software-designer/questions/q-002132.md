# 真题-q-002132

## 题目

在一个容量为128KB的SRAM存储芯片上，按字长32位编址，其地址范围可从0000H到（ ）。

## 选项

- **A.** 3fffH

- **B.** 7fffH

- **C.** 3ffffH

- **D.** 7ffffH

## 参考答案

- **B.** 7fffH
