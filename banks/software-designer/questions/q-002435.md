# 真题-q-002435

## 题目

设由三棵树构成的森林中，第一棵树、第二棵树和第三棵树的结点总数分别为?n1、n2?和n3。将该森林转换为一棵二叉树，那么该二叉树的右子树包含 (   )  个结点。

## 选项

- **A.** n1

- **B.** n1+n2

- **C.** n3

- **D.** n2+n3

## 参考答案

- **D.** n2+n3
