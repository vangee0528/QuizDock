# 真题-q-001760

## 题目

以下关于软件设计原则的叙述中，正确的是（ ）。

## 选项

- **A.** 系统需要划分多个模块，模块的规模越小越好

- **B.** 不考虑信息隐蔽，模块内部的数据可以让其他模块直接访问

- **C.** 尽可能低内聚和高耦合

- **D.** 采用过程抽象和数据抽象设计

## 参考答案

- **D.** 采用过程抽象和数据抽象设计
