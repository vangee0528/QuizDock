# 真题-q-002070

## 题目

组相联映射是常见的 Cache 映射方法。如果容量为 128 块的 Cache 采用组相联方式映射，每块大小为 64 个字，每 4 块为一组，即 Cache 分为（1）组。若主存容量为 4096 块，且以字编址，根据主存与 Cache 块的容量需一致，即每个内存页的大小是（请作答此空）个字，主存地址需要（3）位，主存组号需（4）位。

## 选项

- **A.** 128

- **B.** 64

- **C.** 4096

- **D.** 1024

## 参考答案

- **B.** 64
