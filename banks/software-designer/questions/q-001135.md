# 真题-q-001135

## 题目

进行面向对象系统设计时，针对包中的所有类对于同一类性质的变化；一个变化若对一个 包产生影响，则将对该包中的所有类产生影响，而对于其他的包不造成任何影响。这属于（39） 设计原则。

## 选项

- **A.** 共同重用

- **B.** 开放-封闭

- **C.** 接口分离

- **D.** 共同封闭

## 参考答案

- **D.** 共同封闭
