# 数据结构与算法-q-000346

## 题目

下列伪代码的时间复杂度是（ ）。
for i from 0 to n-1 do
    j = 0
    while j < n do
        j = j + 1
    end while
end for

## 选项

- **A.** O(n)

- **B.** O(n²)

- **C.** O(log n)

- **D.** O(n log n)

## 参考答案

- **B.** O(n²)
