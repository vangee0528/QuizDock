# 真题-q-001484

## 题目

如果将 Students 表的插入权限赋予用户 User1，并允许其将该权限授予他人，那么正确的 SQL 语句如下：
```sql
GRANT （请作答此空） TABLE Students TO User1（56）;
```

## 选项

- **A.** INSERT

- **B.** INSERT ON

- **C.** UPDATE

- **D.** UPDATE ON

## 参考答案

- **B.** INSERT ON
