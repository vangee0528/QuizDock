# 数据结构与算法-q-000383

## 题目

利用动态规划方法求解每对结点之间的最短路径问题（all-pairs shortest path problem）时，设有向图 G=<V,E>，则（ ）。

## 选项

- **A.** D^k(i,j)=D^(k-1)(i,j)+C(i,j)

- **B.** D^k(i,j)=min{D^(k-1)(i,j),D^(k-1)(i,j)+C(i,j)}

- **C.** D^k (i,j)=D^(k-1)(i,k)+D^(k-1)(k,j)

- **D.** D^k(i,j)=min{D^(k-1)(i,j),D^(k-1)(i,k)+D^(k-1)(k,j)}

## 参考答案

- **D.** D^k(i,j)=min{D^(k-1)(i,j),D^(k-1)(i,k)+D^(k-1)(k,j)}
