# 真题-q-001556

## 题目

算术表达式 `b*(a+c)-d` 的后缀式是（ ）（+、-、* 表示算术的加、减、乘运算，运算符的优先级和结合性遵循惯例）。

## 选项

- **A.** ba+cd*-

- **B.** bacd+*-

- **C.** ba*c+d*-

- **D.** bac+*d-

## 参考答案

- **D.** bac+*d-
