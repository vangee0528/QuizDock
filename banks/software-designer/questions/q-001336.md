# 真题-q-001336

## 题目

驱动新能源汽车的发动机时，电能和光能汽车分别采用不同驱动方法，而客户端希望使用统一的驱动方法，需定义一个统一的驱动接口屏蔽不同的驱动方法，该要求适合采用（47）模式

## 选项

- **A.** 中介者（Mediator）

- **B.** 访问者（Visitor）

- **C.** 观察者（Observer）

- **D.** 适配器（Adapter）

## 参考答案

- **D.** 适配器（Adapter）
