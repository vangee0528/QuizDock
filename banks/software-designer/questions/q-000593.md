# 数据库-q-000593

## 题目

给定关系模式R<U，F>，U={A，B，C}，F={AB→C，C→B}。关系R（请作答此空） ，且分别有（2） 。

## 选项

- **A.** 只有1个候选关键字AC

- **B.** 只有1个候选关键字AB

- **C.** 有2个候选关键字AC和BC

- **D.** 有2个候选关键字AC和AB

## 参考答案

- **B.** 只有1个候选关键字AB
