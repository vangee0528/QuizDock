# 真题-q-001158

## 题目

对数组A=(2,8,7,1,3,5,6,4)用快速排序算法的划分方法进行一趟划分后得到的数组A 为（请作答此空） （非递减排序，以最后一个元素为基准元素）。进行一趟划分的计算时间为（2）。

## 选项

- **A.** (1,2,8,7,3,5,6,4)

- **B.** (1,2,3,4,8,7,5,6)

- **C.** (2,3,1,4,7,5,6,8)

- **D.** (2,1,3,4,8,7,5,6)

## 参考答案

- **C.** (2,3,1,4,7,5,6,8)
