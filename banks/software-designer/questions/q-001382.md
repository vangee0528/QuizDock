# 真题-q-001382

## 题目

嵌入式操作系统的（23）是指：从减少成本和缩短研发周期考虑，要求操作系统能针对硬件变化进行结构与功能上的配置，以满足不同微处理器平台的要求。

## 选项

- **A.** 实时性

- **B.** 可靠性

- **C.** 可定制性

- **D.** 易移植性

## 参考答案

- **C.** 可定制性
