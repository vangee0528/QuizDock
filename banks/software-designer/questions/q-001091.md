# 法律法规与知识产权-q-001091

## 题目

软件产品没有固化到磁盘等物理设备，（ ）。

## 选项

- **A.** 不受法律保护

- **B.** 仍然受法律保护

- **C.** 只有固化后才受法律保护

- **D.** 仅在发表后受法律保护

## 参考答案

- **B.** 仍然受法律保护
