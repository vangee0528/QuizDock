# 软件工程-q-000769

## 题目

针对“关键职员在项目未完成时就跳槽”的风险，最不合适的风险管理策略是（  ）。

## 选项

- **A.** 对每一个关键性的技术人员，要培养后备人员

- **B.** 建立项目组，以使大家都了解有关开发活动的信息

- **C.** 临时招聘具有相关能力的新职员

- **D.** 对所有工作组织细致的评审

## 参考答案

- **C.** 临时招聘具有相关能力的新职员
