# 真题-q-001402

## 题目

UML 序列图是业务场景的图形化表示，描述了以（41）顺序组织的对象之间的交互活动。某系统中的一个 UML 序列图如下图所示，（42）表示返回消息，`Account` 类必须实现的方法有（请作答此空）。

![题目图片](../assets/95dc513903d8b0add1d68ee35983d726f40a4b4dfd2aa1f153c4b9575148ebea.jpg)

## 选项

- **A.** `start()`

- **B.** `checkBalance()` 和 `withdraw()`

- **C.** `deposit()`

- **D.** `checkBalance()`、`withdraw()` 和 `deposit()`

## 参考答案

- **D.** `checkBalance()`、`withdraw()` 和 `deposit()`
