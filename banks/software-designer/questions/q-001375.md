# 真题-q-001375

## 题目

在划分模块时，一个模块的作用范围应该在其控制范围之内。若发现其作用范围不在其控制范围内，则  (  16 )  不是适当的处理方法。

## 选项

- **A.** 将判定所在模块合并到父模块中，使判定处于较高层次

- **B.** 将受判定影响的模块下移到控制范围内

- **C.** 将判定上移到层次较高的位置

- **D.** 将父模块下移，使判定处于较高层次

## 参考答案

- **D.** 将父模块下移，使判定处于较高层次
