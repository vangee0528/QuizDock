# 软件工程-q-000852

## 题目

关于程序模块优化的启发式规则有若干条，以下规则中不符合优化原则的是（作答此空）。如果一个模块调用下层模块时传递一个数据结构，则这种耦合属于（ ）。

## 选项

- **A.** 通过模块的合并和分解，降低模块的耦合度，提高模块的内聚性

- **B.** 提高上层模块的扇出，减少模块调用的层次

- **C.** 将模块的作用范围限制在模块的控制范围之内

- **D.** 降低模块之间接口的复杂性，避免“病态连接”

## 参考答案

- **B.** 提高上层模块的扇出，减少模块调用的层次
