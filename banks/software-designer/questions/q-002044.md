# 真题-q-002044

## 题目

假定某企业2014年5月的员工工资如下表所示：

查询人数大于 2 的部门和部门员工应发工资的平均工资的 SQL 语句如下：

```sql
SELECT （ ）
FROM 工资表
（请作答此空）
（ ）；
```

## 选项

- **A.** `ORDER BY 姓名`

- **B.** `ORDER BY 部门`

- **C.** `GROUP BY 姓名`

- **D.** `GROUP BY 部门`

## 参考答案

- **D.** `GROUP BY 部门`
