# 真题-q-002351

## 题目

设关系模式 R（U，F），其中：U= {A，B，C，D，E}，F={A→B，DE→B，CB→E，E→A，B→D}。（ ）为关系模式R的候选关键字。分解（本题）是无损连接，并保持函数依赖的。

## 选项

- **A.** ρ={ R1(AC),R2(ED),R3(B) }

- **B.** ρ={ R1(AC),R2(E),R3(DB) }

- **C.** ρ={ R1(AC),R2(ED),R3(AB) }

- **D.** ρ={ R1(ABC),R2(ED),R3(ACE) }

## 参考答案

- **D.** ρ={ R1(ABC),R2(ED),R3(ACE) }
