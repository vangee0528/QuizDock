# 真题-q-001492

## 题目

对一组数据进行排序，要求排序算法的时间复杂度为 O(n log n)，且要求排序是稳定的，则可采用（62）算法。若要求排序算法的时间复杂度为 O(n log n)，且在原数据上进行，即空间复杂度为 O(1)，则可采用（请作答此空）算法。

## 选项

- **A.** 直接插入排序

- **B.** 堆排序

- **C.** 快速排序

- **D.** 归并排序

## 参考答案

- **B.** 堆排序
