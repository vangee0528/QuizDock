# 真题-q-001361

## 题目

以下关于SRAM和DRAM储存器的叙述中正确的是 ( 2 )  。

## 选项

- **A.** 与DRAM相比，SRAM集成率低，功耗大、不需要动态刷新

- **B.** 与DRAM相比，SRAM集成率高，功耗小、需要动态刷新

- **C.** 与SRAM相比，DRAM集成率高，功耗大、不需要动态刷新

- **D.** 与SRAM相比，DRAM集成率低，功耗大、需要动态刷新
