# 真题-q-002133

## 题目

若某存储器存储周期为250ns，每次读出16位，该存储器的数据传输率是（ ）。

## 选项

- **A.** 4*10^6B/s

- **B.** 4*10^20B/s

- **C.** 8*10^6B/s

- **D.** 8*10^20B/s

## 参考答案

- **C.** 8*10^6B/s
