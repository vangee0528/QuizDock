# 真题-q-001267

## 题目

在单处理机计算机系统中，有1台打印机、 1台扫描仪， 系统采用先来先服务调度算法。假设系统中有进程P1、P2、P3、P4，其中P1为运行状态，P2为就绪状态，P3等待打印机，P4等待扫描仪。此时，若P1释放了扫描仪，则进程P1、P2、P3、P4的状态分别为(23)。

## 选项

- **A.** 等待、运行、等待、就绪

- **B.** 运行、就绪、等待、就绪

- **C.** 就绪、就绪、等待、运行

- **D.** 就绪、运行、等待、就绪

## 参考答案

- **B.** 运行、就绪、等待、就绪
