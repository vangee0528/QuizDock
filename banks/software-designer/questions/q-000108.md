# 程序设计语言-q-000108

## 题目

已知 3 个类 O、P 和 Q，类 O 中定义了一个私有方法 F1 和一个公有方法 F2；类 P 中定义了一个公有方法 F3，类 P 为类 O 的派生类，类 Q 为类 P 的派生类，它们的继承方式如下所示：

```cpp
class P : public O { … };
class Q : private P { … };
```

关于类 P 的描述中，正确的是（）。

## 选项

- **A.** 类 P 的对象可以访问 F1，但不能访问 F2

- **B.** 类 P 的对象可以访问 F2，但不能访问 F1

- **C.** 类 P 的对象既可以访问 F1，也可以访问 F2

- **D.** 类 P 的对象既不能访问 F1，也不能访问 F2

## 参考答案

- **B.** 类 P 的对象可以访问 F2，但不能访问 F1
