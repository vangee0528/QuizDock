# 数据库-q-000559

## 题目

给定关系模式R(U,F),其中，属性集U={A,B,C,D,E,G}，函数依赖集F={A→B,A→C,C→D,AE→G}。若将R分解为如下两个子模式（  ），则分解后的关系模式保持函数依赖。

## 选项

- **A.** R1(A,B,C)和R2(D,E,G)

- **B.** R1(A,B,C,D)和 R2(A,E,G)

- **C.** R1(B,C,D)和 R2(A,E,G)

- **D.** R1(B,C,D,E)和 R2(A,E,G)

## 参考答案

- **B.** R1(A,B,C,D)和 R2(A,E,G)
