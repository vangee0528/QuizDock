# 软件工程-q-000989

## 题目

某系统提供了用户信息操作模块，用户可以修改自己的各项信息。为了使操作过程更加人性化，可以使用（46）对系统进行改进，使得用户在进行了错误操作之后可以恢复到操作之前的状态。

## 选项

- **A.** 责任链

- **B.** 备忘录模式

- **C.** 模板方法模式

- **D.** 访问者模式

## 参考答案

- **B.** 备忘录模式
