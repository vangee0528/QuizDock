# 真题-q-002418

## 题目

运用互联网技术，在系统性能评价中通常用平均无故障时间（MTBF）和平均故障修复时间 （MTTR）分别表示计算机系统的可靠性和可用性，下列 （ ） 表示系统具有高可靠性和高可用性。

## 选项

- **A.** MTBF 小，MTTR 小

- **B.** MTBF 大，MTTR 小

- **C.** MTBF 大，MTTR 大

- **D.** MTBF 小，MTTR 大

## 参考答案

- **B.** MTBF 大，MTTR 小
