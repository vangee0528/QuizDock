# 真题-q-001628

## 题目

下列关于虚拟存储器的叙述中，正确的是（ ）。

## 选项

- **A.** 虚拟存储器只能基于连续分配技术

- **B.** 虚拟存储器只能基于非连续分配技术

- **C.** 虚拟存储容量只受外存容量的限制

- **D.** 虚拟存储容量只受内存容量的限制

## 参考答案

- **B.** 虚拟存储器只能基于非连续分配技术
