# 数据库-q-000597

## 题目

52、给定关系模式 R(U,F)，其中U 为属性集，F是U上的一组函数，以下错误的是(52)

## 选项

- **A.** 若Y∈X∈U，则X->Y为F所蕴涵

- **B.** 若X->Y，Y->Z、则X一>Y为F所蕴涵

- **C.** 若X->Y，Z∈Y，刚X一>Z 为F所蕴涵

- **D.** 若X-->Y，X->Z，则X一>YZ为F所蕴涵

## 参考答案

- **B.** 若X->Y，Y->Z、则X一>Y为F所蕴涵
