# 数据库-q-000597

## 题目

52、给定关系模式 R(U,F)，其中U 为属性集，F是U上的一组函数，以下错误的是(52)

## 选项

- **A.** 若 Y∈X∈U，则 X→Y 为 F 所蕴涵

- **B.** 若 X→Y，Y→Z，则 X→Y 为 F 所蕴涵

- **C.** 若 X→Y，Z∈Y，则 X→Z 为 F 所蕴涵

- **D.** 若 X→Y，X→Z，则 X→YZ 为 F 所蕴涵

## 参考答案

- **B.** 若 X→Y，Y→Z，则 X→Y 为 F 所蕴涵
