# 程序设计语言-q-000093

## 题目

某 Python 程序中定义了 `X = [1, 2]`，那么 `X * 2` 的值为（）。

## 选项

- **A.** `[1, 2, 1, 2]`

- **B.** `[1, 1, 2, 2]`

- **C.** `[2, 4]`

- **D.** 出错

## 参考答案

- **A.** `[1, 2, 1, 2]`
