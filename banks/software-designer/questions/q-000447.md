# 操作系统-q-000447

## 题目

假设磁盘的每个磁道分成9个块，现一个文件有A，B，···I共9条记录，每条记录的大小与块的大小相等，设磁盘转速为27ms/z转，每读出一块后需要2ms的处理时间，若忽略其他辅助时间，若顺序存放这些记录顺序读取，处理此文件需要（请作答此空），若对文件记录存放顺序调整优化，处理此文件最短时间为（2）。

## 选项

- **A.** 243ms

- **B.** 245ms

- **C.** 270ms

- **D.** 290ms

## 参考答案

- **B.** 245ms
