# 真题-q-001792

## 题目

假设事务T1对数据D1加了共享锁，事务T2对数据D2加了排它锁，那么 （ ） 。

## 选项

- **A.** 事务T1对数据D2加排它锁和共享锁都失败

- **B.** 事务T1对数据D2加共享锁成功，加排它锁失败

- **C.** 事务T1对数据D2加排它锁或共享锁都成功

- **D.** 事务T2对数据D1加排它锁成功

## 参考答案

- **A.** 事务T1对数据D2加排它锁和共享锁都失败
