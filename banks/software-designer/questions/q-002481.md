# 真题-q-002481

## 题目

以下关于面向对象技术中类和对象的关系描述，正确的是（ ）。

## 选项

- **A.** 类是对象的具体实例

- **B.** 一个类只能创建一个对象

- **C.** 类是模板，对象是根据模板创建的实例

- **D.** 对象是抽象的，类是具体的

## 参考答案

- **C.** 类是模板，对象是根据模板创建的实例
