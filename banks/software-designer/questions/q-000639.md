# 计算机网络-q-000639

## 共用题干

在 Linux 操作系统中通常使用（1）作为 Web 服务器，其默认的 Web 站点目录为（2）。

## 各空选项

### 第 1 空

- **A.** IIS

- **B.** Apache

- **C.** NFS

- **D.** MySQL

### 第 2 空

- **A.** /etc/httpd

- **B.** /var/log/httpd

- **C.** /etc/home

- **D.** /home/httpd

## 参考答案

- 第 1 空：**B.** Apache

- 第 2 空：**D.** /home/httpd
