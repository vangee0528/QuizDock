# 真题-q-001313

## 题目

进程P1、P2、P3、P4、P5和P6的前趋图如下所示。假设用PV操作来控制这6 个进程的同步与互斥的程序如下，程序中的空①和空②处应分别为_（请作答此空）。空③和空④处应分别为（2），空⑤和空⑥处应分别为（3）.

![题目图片](../assets/67db00531c25a49cb0ad25c6852a0d6c00259d0898b871da706e0bba27ba6499.png)

## 选项

- **A.** V（S1）V（S2）和P（S2）P（S3）(24空)

- **B.** V（SI）P（S2）和V（S3）P（S4）(24空)

- **C.** V（S1）V（S2）和V（S3）V（S4）(24空)

- **D.** P（SI）P（S2）和V（S2）V（S3）(24空)

## 参考答案

- **C.** V（S1）V（S2）和V（S3）V（S4）(24空)
