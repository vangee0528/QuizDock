# 真题-q-002426

## 题目

给定关系模式 R(U,F)，其中U 为属性集，F是U上的一组函数，则根据Armstrong公理，合并规则是指  (  )  。

## 选项

- **A.** 若Y∈X∈U，则X->Y为F所蕴含

- **B.** 若X->Y，Y->Z，则X->Y为F所蕴含

- **C.** 若X->Y，Z∈Y，则X->Z 为F所蕴含

- **D.** 若X->Y，X->Z，则X->YZ为F所蕴含
