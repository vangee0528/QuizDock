# 真题-q-001908

## 题目

假设指令流水线把一条指令分为取指、分析、执行 3 个部分，且 3 个部分的时间分别是 `t1 = 2 ns`、`t2 = 2 ns`、`t3 = 1 ns`，则 100 条指令全部执行完需要（ ）。

## 选项

- **A.** 163 ns

- **B.** 183 ns

- **C.** 193 ns

- **D.** 203 ns

## 参考答案

- **D.** 203ns
