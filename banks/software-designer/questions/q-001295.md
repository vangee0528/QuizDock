# 真题-q-001295

## 题目

## 选项

- **A.** 可以保持加法和减法运算过程与手工运算方式一致

- **B.** 可以提高运算过程和结果的精准程度

- **C.** 可以提高加法和减法运算的速度

- **D.** 可以将减法运算转化为加法运算从而简化运算器的设计
