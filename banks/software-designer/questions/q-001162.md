# 真题-q-001162

## 题目

采用 DHCP 动态分配IP 地址，如果某主机开机会没有得到 DHCP 服务器的相应响应， 则依主机获取的 IP 地址属于网络（请作答此空）.

## 选项

- **A.** 202.117.0.0/16

- **B.** 192.168.1.0/24

- **C.** 172.16.0.0/24

- **D.** 169.254.0.0/16

## 参考答案

- **D.** 169.254.0.0/16
