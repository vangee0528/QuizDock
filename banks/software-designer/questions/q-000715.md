# 软件工程-q-000715

## 题目

某搜索引擎在交付后，开发人员修改了其中的索引方法，使得用户可以更快地得到搜索结果。这种修改属于（）维护。

## 选项

- **A.** 正确性

- **B.** 适应性

- **C.** 完善性

- **D.** 预防性

## 参考答案

- **C.** 完善性
