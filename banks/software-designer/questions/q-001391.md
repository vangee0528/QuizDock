# 真题-q-001391

## 题目

某文件管理系统采用位示图（bitmap）记录磁盘的使用情况。如果系统的字长为32位，磁盘物理块的大小为4MB，物理块依次编号为：0、1、2、位示图字依次编号为：0、1、2、那么16385号物理块的使用情况在位示图中的第(25)个字中描述;如果磁盘的容量为1000GB,那么位示图需要（请作答此空）个字来表示。

## 选项

- **A.** 1200

- **B.** 3200

- **C.** 6400

- **D.** 8000

## 参考答案

- **D.** 8000
