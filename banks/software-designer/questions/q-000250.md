# 数据结构与算法-q-000250

## 题目

已知一个二叉树的先序遍历序列为①、②、③、④、⑤，中序遍历序列为②、①、④、③、⑤，则该二叉树的后序遍历序列为（  ）。对于任意一棵二叉树，叙述错误的是（  ）。

## 选项

- **A.** 由其后序遍历序列和中序遍历序列可以构造该二叉树的先序遍历序列

- **B.** 由其先序遍历序列和后序遍历序列可以构造该二叉树的中序遍历序列

- **C.** 由其层序遍历序列和中序遍历序列可以构造该二叉树的先序遍历序列

- **D.** 由其层序遍历序列和后序遍历序列不能构造该二叉树的中序遍历序列

## 参考答案

- **B.** 由其先序遍历序列和后序遍历序列可以构造该二叉树的中序遍历序列
