# 数据结构与算法-q-000295

## 题目

设顺序存储的某线性表共有123个元素，按分块查找的要求等分为3块。若对索引表采用顺序查找方法来确定子块，且在确定的子块中也采用顺序查找方法，则在等概率的情况下，分块查找成功的平均查找长度为（ ）。

## 选项

- **A.** 21

- **B.** 23

- **C.** 41

- **D.** 62

## 参考答案

- **B.** 23
