# 数据结构与算法-q-000348

## 题目

案例四（15 分）

阅读下列说明和 C 代码，回答问题，将解答填入答题纸的对应栏内。

【说明】
凸多边形是指多边形的任意两点的连线均在多边形的边界或内部。相邻点的连线称为多边形的边。假设任意两条边不相交。凸多边形的三角剖分是将凸多边形划分为互不相交的若干三角形。每个三角形的权重为其三条边权重之和。

设有 N 个点的凸多边形，点编号为 V₁、V₂、…、Vₙ。若在 Vₖ 处将原凸多边形划分为一个三角形和两个子多边形，得到一个最优的剖分方案，则该最优剖分方案应该包含这两个子多边形的最优剖分方案。

用 m[i][j] 表示由 Vᵢ₋₁、Vᵢ、…、Vⱼ 构成的凸多边形的最优剖分方案权重，s[i][j] 记录剖分该凸多边形时的 k 值。其递归定义为：

$$m[i][j]=\begin{cases}0,&i\ge j\\\min\limits_{i\le k<j}\{m[i][k]+m[k+1][j]+w(V_{i-1},V_k,V_j)\},&i<j\end{cases}$$

其中 w(Vᵢ₋₁,Vₖ,Vⱼ) 为三角形 Vᵢ₋₁VₖVⱼ 的权重。求解凸多边形的最优剖分方案，即求解最小部分的权重及其对应的三角形集合。
