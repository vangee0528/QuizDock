# 计算机网络-q-000618

## 题目

某网络的IP地址空间为192.168.5.0/24，采用定长子网划分，子网掩码为255.255.255.248，则该网络中的最大子网个数，每个子网内的最大可分配地址的个数（　）。

## 选项

- **A.** 32,8

- **B.** 32,6

- **C.** 8,32

- **D.** 8,30

## 参考答案

- **B.** 32,6
