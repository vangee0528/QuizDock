# 计算机基础-q-000030

## 题目

两个同符号的数相加或异符号的数相减，所得结果的符号位 SF 和进位标志 CF 进行（ ）运算为 1 时，表示运算结果产生溢出。

## 选项

- **A.** 与

- **B.** 或

- **C.** 与非

- **D.** 异或

## 参考答案

- **D.** 异或
