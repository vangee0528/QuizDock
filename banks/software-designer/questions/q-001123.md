# 真题-q-001123

## 题目

假设系统有 n（n≥5）个进程共享资源 R，且资源 R 的可用数为 5。若采用 PV 操作，则 相应的信号量 S 的取值范围应为（27）。

## 选项

- **A.** -1～n-1

- **B.** -5～5

- **C.** -(n-1)～1

- **D.** -(n-5)～5

## 参考答案

- **D.** -(n-5)～5
