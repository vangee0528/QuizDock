# 数据结构与算法-q-000337

## 题目

根据渐进分析，表达式序列：n⁴、log n、2ⁿ、1000n、n^(2/3)、n! 从低到高排序为（ ）。

## 选项

- **A.** log n、1000n、n^(2/3)、n⁴、n!、2ⁿ

- **B.** n^(2/3)、1000n、log n、n⁴、n!、2ⁿ

- **C.** log n、1000n、n^(2/3)、2ⁿ、n⁴、n!

- **D.** log n、n^(2/3)、1000n、n⁴、2ⁿ、n!

## 参考答案

- **D.** log n、n^(2/3)、1000n、n⁴、2ⁿ、n!
