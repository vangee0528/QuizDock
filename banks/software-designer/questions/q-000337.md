# 数据结构与算法-q-000337

## 选项

- **A.** Ign,1000n, n2/3, n4, n!, 2n

- **B.** n2/3,1000n, lgn, n4, n!, 2n

- **C.** lgn,1000n, n2/3, 2n, n4, n!

- **D.** Ign, n2/3, 1000n, n4, 2n, n!
