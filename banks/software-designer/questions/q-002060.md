# 真题-q-002060

## 题目

在某班级管理系统中，班级的班委有班长、副班长、学习委员和生活委员，且学生年龄在15～25岁。若用等价类划分来进行相关测试，则 （ ） 不是好的测试用例。

## 选项

- **A.** (队长，15)

- **B.** (班长，20)

- **C.** (班长，15)

- **D.** (队长，12)

## 参考答案

- **D.** (队长，12)
